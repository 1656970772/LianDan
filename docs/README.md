## 核心结论

- 网页是规则开发工作台，不是实时炼丹玩法。
- 用户只需配置输入并点击一次推演，不存在可交互的中间过程或反应时间线。
- 结果仍要解释丹药身份、品质、功效、副作用、特质与失败原因。
- 丹药是“原型 + 受控修正”的动态结果，所有名称、效果、特质和数值边界均来自配置。
- 规则引擎是无状态纯函数；相同配置、输入和种子必须得到相同输出。
