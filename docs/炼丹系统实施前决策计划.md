# 炼丹系统实施前决策计划

## 1. 文档用途

本文档用于逐项确定炼丹系统开始实施前所需的具体规则。

讨论采用以下流程：

1. 每次只讨论一个主题；
2. 尚未确认的建议不视为最终设计；
3. 用户确认后，将结论写入本文档的对应章节；
4. 当前主题确认完成后，再进入下一主题；
5. 全部必要主题完成后，再确定第一阶段实施范围。

宏观设计和已排除事项见《炼丹系统总体设计》。本文档主要记录可以指导后续实现的具体决策。

## 3. 第一项：成丹结果

### 3.1 本项需要依次确定

1. 一炉炼制可能出现哪些结果类型；
2. 丹药由哪些核心字段组成；
3. 是否存在品质和稳定性，以及二者的关系；
4. 一炉丹药的数量如何表达；
5. 丹药如何命名；
6. 玩家能够看到哪些结果信息；
7. 哪些结果能够保存为丹方。

### 3.2 已确认结论

#### 3.2.1 一炉炼制的基础结果

一炉炼制首先判断是否形成丹药，基础结果分为：

1. **成丹**：形成丹药，继续生成丹药的具体属性和评价；
2. **未成丹**：材料未能凝聚成丹，最终成为药渣、药液或其他无效混合物；
3. **炸炉**：发生严重冲突并导致炼制被迫中断，不能作为毫无征兆的纯随机结果。

系统不另外生成独立的炼制记录。玩家需要保留成功炼制过程时，通过丹方记录相关材料、操作和条件。

#### 3.2.2 成丹后的评价标签

成丹后可以根据最终结果获得以下评价标签：

- **正常丹**：效果正常，没有突出异常；
- **残丹**：已经成形，但效果弱、品质低或药性不完整；
- **废丹**：已经成形，但对角色没有直接服用价值；
- **异丹**：产生了罕见效果或特殊特质。

评价标签不要求互斥，具体组合规则在确定丹药字段和品质规则时继续讨论。

不设置“毒丹”异常评价。毒丹属于玩家可以专门研究和炼制的正式丹药类型，不能因为毒性或副作用较高就被系统自动归为炼制失败或异常产物。

#### 3.2.3 废弃产物的利用

废丹虽然没有直接服用价值，但不是无用垃圾，可以用于：

- 喂养灵宠或灵兽；
- 作为种植材料或肥料；
- 后续系统允许的其他资源转化用途。

未成丹留下的药渣也具有类似的再利用价值。具体用途和收益以后在相关系统中设计，本阶段先确定废丹与药渣均可作为产物保留和利用。

#### 3.2.4 当前讨论进度

第一项“成丹结果”已经全部确认。下一步进入第二项“材料反应”。

#### 3.2.5 丹药的核心字段

丹药包含以下核心字段：

1. **主功效**：丹药最主要的用途和效果；
2. **次要功效**：炼制过程中附带形成的其他效果，可以没有，也可以存在多个；
3. **副作用**：服用或使用丹药时可能产生的不利效果；
4. **特殊特质**：不能用普通功效直接表达的特殊作用或规则，例如用于吸引灵兽；
5. **品质**：分为下品、中品、上品和极品。

丹药暂时不保留寒、凉、平、温、热，以及金、木、水、火、土、阴、阳等最终属性。这些信息可以参与材料和炼制过程，但不作为成丹后的独立字段。

丹药不设置独立的“效果强度”字段。效果及其程度统一包含在具体功效的定义中，不再建立一项与功效平行的总强度。

副作用与品质相互独立。即使是上品或极品丹药，也可能具有副作用；高品质不能自动消除副作用。

“正常丹、残丹、废丹、异丹”是根据炼制结果得出的评价标签，不作为与功效并列的核心字段。

丹纹概念继续保留，但当前基本炼丹暂不实现。丹纹不进入丹药字段、名称、Tips、炼制表现或丹方唯一性判定。

#### 3.2.6 稳定性字段

丹药不设置独立的稳定性字段。相关情况按照实际作用归入已有字段：

- 容易变质、遇火爆炸等特殊性质归入特殊特质；
- 服用后药力失控等不利影响归入副作用；
- 炼制不完整通过残丹评价或品质表达；
- 保存期限等内容等到确实设计储存玩法时再考虑。

品质用于表达丹药的炼制水准，不承担稳定性或安全性的全部含义。

#### 3.2.7 一炉丹药的数量规则

投入材料的总有效药量只决定本炉可能萃取出的灵液理论上限。实际丹药数量由接液容器中最终收集到的有效灵液量决定，不受材料比例或丹炉容量限制。

基础规则如下：

- 每颗丹药需要满足最低有效灵液量；
- 投入材料的理论灵液上限不足一颗丹药最低要求时，不能开始炼制；
- 玩家误烧、漏接的灵液不计入后续成形和数量；
- 接住的药渣和杂质不增加有效灵液量，只作为污染输入；
- 实际收集的有效灵液不足一颗丹药最低要求时，不能成丹；
- 完成萃取后，丹药数量不再因无原因的随机额外扣减；
- 残丹和废丹均属于已经形成的丹药，正常计入成丹数量；
- 不足以形成一颗丹药的剩余零散灵液在炼制结束后转化为药渣或其他未成丹产物。

当玩家已经知道目标丹药或使用已知丹方炼制时，丹方记录发现该丹药时使用的材料数量，但这些数量不构成成丹身份的固定比例：

- 将丹方记录的全部材料数量等量放大为两倍时，可生成的掉落物和灵液理论上限相应增加；
- 只有按照重放过程实际收集到对应倍数的有效灵液时，最终成丹数量才会同比增加；
- 改变不同材料之间的数量关系不会产生“偏离标准比例”的判定；
- 只要所需标签、状态和反应过程仍然成立，材料比例本身不改变丹药身份。

未成丹时不产出丹药，材料转化为药渣。炸炉时，全部投入材料都转化为药渣，但最终能够回收的药渣数量较少，不能按投入材料等量回收。

成功形成丹药时仍可能同时产出药渣。正常成功结果中的药渣来自萃取时落到容器两侧、没有被容器接住且仍有剩余体积的精灵珠；这些珠子退出活动模拟后，按照剩余体积进入本炉的炉底药渣池，在最终成丹时统一换算并随丹药一起产出。火焰已经烧掉的体积不产生药渣，只触发护盾但未实际缩小的珠子按100%计算，完全烧毁的珠子不进入药渣池。

正常成丹药渣使用与失败药渣相同的一份药渣标准体积换算：炉底药渣池总体积除以标准体积并向下取整；首版默认100个满体积标准精灵珠的总体积等于一份药渣。药渣池为空时不产出药渣，只要池中有内容就至少产出一份。三类来源统一转化为普通药渣，全部数量合并在一个结果物上并由Tips显示“药渣 × 数量”。成丹时丹药按颗飞出，药渣结果物另外飞出。

#### 3.2.8 丹药与丹方命名

丹药名称完全由配置驱动。系统不生成“未命名丹药”“带有某种效果的丹药”等临时描述名称，也不根据功效自动提供候选名称。

丹药的系统默认显示格式为：

> 配置中的丹药名 + 品阶

例如：

> 回春丹·上品

玩家可以修改丹药名称。

丹方暂时使用与对应丹药相同的名称信息，并在末尾增加“丹方”二字：

> 配置中的丹药名 + 品阶 + 丹方

例如：

> 回春丹·上品丹方

快速炼制产生的轻微变化主要发生在具体功效内部的属性或参数上，不因此改变丹药的基础名称或丹方名称。

当环境影响或随机机制触发异变时，在本次成丹的名称末尾增加“异变”二字：

> 配置中的丹药名 + 品阶 + 异变

异变只改变本次丹药的显示名称，原丹方名称保持不变。

#### 3.2.9 结果展示方式

炼制结束后不打开独立的结果清单界面。成丹时，实际产出的丹药从丹炉中飞出；一炉产出多颗丹药时，对应飞出多颗丹药。

玩家将鼠标移动到丹药上时，显示丹药 Tips。Tips 集中展示该丹药的全部信息，包括：

- 名称；
- 品阶；
- 是否异变；
- 主功效；
- 次要功效；
- 副作用；
- 特殊特质；
- 正常丹、残丹、废丹或异丹等评价信息。

异变不只在最终名称及 Tips 中显示，还需要在炼制过程中产生对应的视觉、声音或其他效果表现。具体表现方式在“炼制反馈”主题中讨论。

药渣与丹药采用相同的产出表现方式：药渣从丹炉中飞出，玩家将鼠标移动到药渣上时显示药渣 Tips。药渣 Tips 的具体字段以后结合药渣用途确定。

系统不设置独立的炼制记录页面或历史记录。丹方本身就是炼制过程的记录，负责保存能够复现对应结果的材料、投入顺序、火候和相关外部条件。

#### 3.2.10 丹方保存资格

只要实际形成了丹药，就可以保存丹方，不限制丹药是否具有直接服用价值：

- 正常丹可以保存丹方；
- 残丹可以保存丹方；
- 废丹可以保存丹方；
- 异丹可以保存丹方。

未成丹、药渣和炸炉不能保存丹方，因为这些结果没有形成丹药。系统也不会为它们另外生成历史记录。

异变丹药可以保存丹方，但丹方名称不增加“异变”二字。未来使用该丹方快速炼制时，异变仍需满足对应环境条件或随机触发条件，不保证每次出现。

## 4. 第二项：材料反应

### 4.1 本项需要依次确定

1. 材料自身保存哪些数据；
2. 材料特性标签分为哪些类别；
3. 标签只用于展示，还是也参与规则匹配；
4. 成丹配置如何匹配材料标签、材料状态和投入顺序；
5. 完全匹配、近似匹配和未匹配分别产生什么结果；
6. 材料状态和年份如何参与匹配；
7. 催化、稳定、黏合、挥发等特殊标签如何作用；
8. 隐藏反应如何配置和触发；
9. 玩家能够看到哪些标签和成丹线索。

### 4.2 已确认结论

#### 4.2.1 材料与成丹的基础模型

材料不设置用于合成功效的具体属性数值，不采用“将多种材料的功效点数相加，再选出最高功效”的计算方式。

材料自身暂时保留：

- 配置身份和名称；
- 可用数量；
- 新鲜、干燥、腐败、冰封等保存状态；
- 野生、种植、变异等生长状态；
- 年份；
- 五类特性标签；真正参与效果或反应结果的标签可以带有配置强度。

材料标签用于描述材料特征并为玩家探索提供推理线索，例如药性倾向、功效倾向或易挥发、寒毒等特殊性质。标签可以携带自身的配置强度，但不采用根据材料投入数量累加属性点数的方式。

丹药的以下最终内容直接定义在成丹配置中：

- 系统丹药名称；
- 主功效；
- 次要功效；
- 副作用；
- 特殊特质；
- 其他已经确定的成丹结果信息。

基础成丹逻辑改为：

> 材料标签与状态 + 投入顺序 + 火候 + 丹炉 + 环境 + 天时 → 匹配成丹配置 → 生成配置中定义的丹药

没有匹配到正常成丹配置时，根据具体偏差和过程结果生成残丹、废丹、药渣或炸炉。具体匹配与偏差规则后续逐项确定。

#### 4.2.2 标签参与规则匹配

材料特性标签必须参与规则匹配，不能只作为界面上的描述文本。玩家需要依据材料标签对可能出现的结果作出有逻辑的猜测。

标签可以携带用于结果判定的强度，但相同标签不会因为重复投入相同材料而累加强度。标签及其强度可以作为以下配置规则的条件：

- 普通成丹规则；
- 材料之间的特殊反应；
- 隐藏反应；
- 环境规则；
- 天时规则；
- 异变触发条件。

系统负责提供通用的标签条件匹配能力，不在代码中写死某组标签必然产生什么结果。具体标签的含义、标签组合与结果之间是否合理，以及玩家能否根据线索推测，由内容配置负责保证。

同一个标签在不同配置中的语义应当保持一致，避免玩家已经建立的认知被没有线索的例外规则破坏。

#### 4.2.3 材料标签的分类与来源

材料标签暂时分为以下五类：

1. **药性标签**：描述材料自身倾向，例如寒凉、炽热、阴森、阳烈；
2. **功效线索标签**：提示可能产生的功效，例如止血、生肌、解毒、引兽、安神；
3. **反应特性标签**：描述炼制时的行为，例如挥发、催化、稳定、黏合、易燃；
4. **风险标签**：提示可能产生副作用或危险反应，例如寒毒、腐化、爆裂、噬魂；
5. **状态标签**：描述材料当前状态，例如鲜活、干燥、腐败、冰封、野生、种植、变异、百年。

标签分为两种来源：

- **固有标签**：直接配置在材料上，不随当前材料批次改变；
- **状态标签**：根据材料的保存状态、生长状态和年份动态产生。

标签分类用于配置管理、规则检查和界面展示，不限制不同类别的标签共同参与同一条规则匹配。

标签名称、分类、说明和其他必要信息全部通过配置维护。当前只确定分类结构，不在本阶段一次性确定完整标签词表。

#### 4.2.4 标签与材料反应的通俗理解

材料反应可以借鉴化学反应的思路，但不需要真的模拟分子、化学式和复杂计算。系统只需要让玩家能够理解“材料为什么会发生这种变化”。

可以把一炉炼丹理解为把各种材料的特点放进同一个丹炉：

- 材料决定这一炉可能出现哪些药性、功效和风险；
- 投药时机决定材料有没有被充分提取，或者是否因为加入过早而损失；
- 火的种类和大小决定材料是缓慢释放、快速反应、挥发、烧毁还是爆裂；
- 环境不是简单增加或减少数值，而是改变某些反应能否发生以及发生方式；
- 天时通过月相、节气和特殊天象，为整炉炼制提供共同条件；
- 异变只能从本炉已经存在的材料和反应中产生，不能毫无原因地随机出现。

本节所说的药性增强、削弱、流失或冲突，不代表材料之间存在可累加的隐藏属性点数。系统通过标签的增加、移除、替换、保留状态和配置分支表达这些变化，最终丹药的功效内容仍然来自成丹配置。

材料之间不需要逐对配置固定结果。系统应优先配置少量可以重复使用的通用反应规则。例如：

- 带有“挥发”标签的材料遇到大火或长时间炼制时，相关药性可能流失；
- 带有“易燃”标签的材料遇到高温和助燃条件时，可能快速放热并增加爆裂风险；
- “催化”会加快其他反应，既可能帮助炼成，也可能让危险反应更快失控；
- “稳定”可以减缓药性损失或压制冲突，为玩家争取更长的操作时间；
- “黏合”有助于凝丹，但过多时也可能包裹其他材料，使药性无法充分融合；
- 寒凉与炽热可能互相抵消；如果同时存在稳定、催化或特殊环境，也可能转化为新的隐藏反应；
- 吸附类材料可以减少毒性和杂质，但使用不当时也可能连同有用药性一起带走；
- 鲜活材料含水较多，遇猛火时反应更剧烈；干燥材料更稳定，但部分容易挥发的药性可能已经减少；
- 腐败材料的原有功效可能受损，并更容易产生腐化、烟毒等风险；

这些通用反应优先匹配标签和炼制条件，不绑定某两个具体材料的名字。正式丹药的成丹配置可以同时使用材料身份、标签、状态、投入顺序和过程条件，但不使用固定材料比例或比例容差；只有少量具有特殊世界观意义的组合才需要强制指定具体材料。以后新增材料时，只要为它配置已有标签，就能够自动参与已有通用反应，不需要为它与所有旧材料分别补写组合规则。

#### 4.2.5 五类标签与化学知识的参考映射

化学知识只作为标签设计和反应设计的参考，不要求与现实化学完全对应。玩家看到的仍然是符合炼丹世界观的名称，系统借用现实中的挥发、燃烧、吸附、沉淀和结晶等因果关系，让结果更容易理解。

每个标签至少配置稳定 ID、名称、分类和说明。材料只引用标签，不在每份材料中重复定义标签含义。以后如果修改标签名称或说明，所有引用该标签的材料和规则都能一起生效。

##### 4.2.5.1 药性标签

药性标签描述材料整体偏向，不直接等于最终功效。

| 标签示例 | 可以借鉴的化学或生理现象 | 玩家容易理解的表现 |
| --- | --- | --- |
| 寒凉 | 吸热、抑制反应、收缩倾向 | 压制炽热与躁动，过量时可能积累寒毒 |
| 炽热 | 放热、促进反应、扩张倾向 | 加快提取与融合，过强时容易烧毁或失控 |
| 阴森 | 缺氧、还原、抑制性环境 | 容易保存阴性效果，也可能滋生腐化 |
| 阳烈 | 富氧、氧化、高能环境 | 有利于净化和快速反应，也更容易燃烧 |
| 酸涩 | 酸性、收敛、使部分成分凝聚 | 容易形成止血或沉淀效果，也可能产生腐蚀 |
| 碱烈 | 碱性、分解油脂和部分组织 | 有利于溶解某些材料，过强时可能灼伤或腐蚀 |
| 油润 | 脂溶、疏水、成膜 | 容易保存脂溶性药性，但不容易与水性材料融合 |
| 清灵 | 杂质少、容易扩散 | 功效较纯粹，但也可能容易挥发和流失 |
| 厚重 | 矿物性、高密度、难溶 | 稳定耐火、适合成核，但需要高温或催化提取 |

寒凉和炽热是炼丹世界中的药性，不必严格等同于现实温度。这里只借用“抑制与促进、吸热与放热”的关系帮助设计规则。

##### 4.2.5.2 功效线索标签

功效线索表示材料可能参与形成什么效果，但不保证投入后一定得到该功效。是否保留下来，还要看其他材料、投入顺序、火候、环境和凝丹时机。

| 标签示例 | 可以借鉴的原理 | 可能关联的材料特点 |
| --- | --- | --- |
| 止血 | 收敛、凝聚、吸附或促进凝结 | 酸涩、黏合、矿物粉末 |
| 生肌 | 营养、成膜、保持湿润 | 鲜活、油润、黏合 |
| 解毒 | 中和、吸附、分解或固定毒物 | 吸附、稳定、酸性、碱性、催化 |
| 引兽 | 挥发性气味扩散 | 芳香、腥膻、挥发 |
| 安神 | 抑制性、芳香或脂溶性成分 | 阴性、芳香、油润 |
| 麻痹 | 抑制或阻断刺激传递 | 阴毒、挥发、脂溶 |
| 提神 | 刺激性成分快速释放 | 辛烈、挥发、阳性 |
| 强身 | 稳定营养或矿物补充 | 厚重、生机、温和 |
| 驱寒 | 放热、刺激和促进循环 | 炽热、辛烈、阳性 |
| 清热 | 吸热、抑制和收敛 | 寒凉、苦涩、阴性 |

同一个功效可以有不同形成方法。例如“解毒”既可能来自酸碱中和，也可能来自吸附毒物或催化分解，因此不同解毒丹可以拥有不同材料要求和副作用。

##### 4.2.5.3 反应特性标签

反应特性标签负责说明材料进入丹炉以后会怎么行动，是通用反应规则最主要的匹配对象。

| 标签示例 | 化学参考 | 炼制表现 |
| --- | --- | --- |
| 挥发 | 沸点低、蒸气压高 | 高温或久炼时离开药液 |
| 催化 | 降低反应发生门槛 | 加快有益反应，也会加快危险反应 |
| 稳定 | 抗氧化、缓冲、抑制分解 | 保护脆弱药性，减缓冲突与失控 |
| 黏合 | 凝胶、聚合、成膜 | 帮助凝丹，过多时会包裹其他成分 |
| 易燃 | 快速氧化并放热 | 遇高温和助燃条件时燃烧或爆裂 |
| 吸附 | 多孔结构吸附其他物质 | 可以吸走毒素，也可能吸走有效药性 |
| 酸性 | 提供酸性反应条件 | 可以与碱性中和，或使某些成分沉淀 |
| 碱性 | 提供碱性反应条件 | 可以分解或溶解部分材料，也可能腐蚀 |
| 氧化 | 促进其他成分被氧化 | 可以净化腐败，也可能破坏脆弱功效 |
| 还原 | 抵消或抑制氧化 | 有助于保留怕氧化的药性 |
| 易溶 | 容易进入药液 | 提取快，也可能因炼制过久而过度反应 |
| 难溶 | 不容易进入药液 | 需要高温、较长炼制过程或催化 |
| 沉淀 | 与特定成分结合成为固体 | 可以去除杂质，也可能损失功效 |
| 凝胶 | 吸水后形成胶状结构 | 增加黏度和成丹能力，但降低流动与融合 |
| 成核 | 容易形成结晶起点 | 帮助药液开始凝丹，改善丹形 |
| 吸湿 | 容易吸收环境水分 | 在潮湿环境下更容易软化、结团或水解 |
| 光敏 | 受到光照时发生变化 | 可能在日光、月光或特殊天象下改变反应 |

项目最终可以把“酸性、碱性、氧化、还原”等术语替换成更符合世界观的名称，但底层关系仍可参考这些化学现象。

##### 4.2.5.4 风险标签

风险标签既可以是材料自带的警告，也可以在炼制过程中因为错误操作或危险反应临时产生。

| 标签示例 | 产生原因 | 可能结果 |
| --- | --- | --- |
| 寒毒 | 寒凉药性过强且没有中和 | 形成服用后的寒性副作用 |
| 火毒 | 炽热或刺激性药性过强 | 形成灼热、躁动等副作用 |
| 腐化 | 材料腐败、氧化或发生错误分解 | 原功效改变，产生腐败类副作用 |
| 爆裂 | 快速放热、产气或炉压升高 | 炉内冲击、丹药破碎或炸炉 |
| 腐蚀 | 酸碱或活泼成分过强 | 损伤丹炉、材料或服用者 |
| 烟毒 | 有毒成分挥发 | 污染丹炉环境或形成吸入风险 |
| 药性冲突 | 不相容、沉淀或冷热对抗 | 功效损失、残丹或特殊转化 |
| 噬魂 | 幻想能量或魂性材料污染 | 产生精神、魂魄方面的副作用 |
| 反噬 | 功效过强但缺少稳定与控制 | 药力失控，功效转化为副作用 |
| 丹毒 | 杂质和副产物没有被去除 | 成丹后留下通用毒性或负担 |

噬魂等标签没有现实化学对应物，可以保留为纯幻想规则，但仍应有明确来源和触发条件。

##### 4.2.5.5 状态标签

状态标签描述的不是材料天生是什么，而是这一批材料目前处于什么状态。它们只根据保存状态、生长来源和年份自动获得。

| 标签示例 | 现实参考 | 对炼制的影响方向 |
| --- | --- | --- |
| 鲜活 | 含水较多、酶仍活跃 | 生机较强，遇猛火时可能剧烈汽化 |
| 干燥 | 含水较少 | 保存相对稳定，但部分挥发成分可能已经减少 |
| 腐败 | 成分分解、微生物作用 | 原功效下降或改变，腐化与烟毒风险增加 |
| 冰封 | 低温保存、组织受冻 | 挥发受到抑制，解冻后可能快速释放成分 |
| 野生 | 成分复杂且波动较大 | 可能上限更高，也更容易带有杂质或异变线索 |
| 种植 | 生长条件稳定 | 表现更容易预测，特殊变化较少 |
| 变异 | 成分比例或结构异常 | 改变原标签关系，增加特殊反应可能 |
| 百年 | 长期积累和缓慢转化 | 主要药性更突出，也可能积累厚重或特殊风险 |
例如，材料在潮湿环境中存放过久可以自动获得“腐败”，达到规定年份后自动获得对应年份标签。玩家不需要手工编辑标签，标签由材料当前的保存状态、来源和年份自动生成。

#### 4.2.6 可以重复使用的基础反应

下面这些反应不绑定具体材料名称，可以由任意带有对应标签的材料触发。它们是后续反应规则配置的主要参考，不代表本阶段已经确定全部标签名称和精确判定条件。

##### 4.2.6.1 酸碱中和

当酸性或酸涩材料与碱性材料相遇时，双方可以发生中和：

- 双方原本的腐蚀倾向减弱；
- 某些毒性可能被中和；
- 反应可能放热，因此短时间内炉温或炉压上升；
- 反应可能生成沉淀，使部分功效一起离开药液；
- 如果投料过快或丹炉密闭，温和的中和也可能变成沸腾或爆裂。

因此中和不是简单地把两个标签删除，而是可能同时解决一个风险并产生新的处理问题。

##### 4.2.6.2 氧化与还原

氧化性材料、阳火或富氧环境可以促进氧化；还原性材料、阴火或缺氧环境可以抑制氧化：

- 适度氧化可以去除部分腐败和杂质；
- 过度氧化会破坏鲜活、生肌、安神等脆弱药性；
- 还原与稳定可以保护怕氧化的成分；
- 氧化材料与还原材料直接相遇时可能快速反应、变色或放热；
- 催化材料会让上述变化更快发生，玩家能够操作的时间也会缩短。

##### 4.2.6.3 挥发与炉压

带有挥发标签的材料进入高温阶段后，相关成分会逐渐离开药液：

- 丹炉开放时，挥发成分直接散失，对应功效难以保留；
- 丹炉密闭时，挥发成分可以暂时留在炉内，但炉压会升高；
- 后期投入、文火处理和及时凝丹更容易保留挥发性功效；
- 高温、久炼和催化会加快挥发；
- 有毒材料发生挥发时，可能形成烟毒，而不是简单消失。

这使“打开丹炉减少爆裂风险”和“密闭丹炉保留药性”形成明确取舍。

##### 4.2.6.4 燃烧与爆裂

易燃材料只有在合适条件下才会真正危险。典型危险链条是：

> 易燃材料 + 高温 + 阳火或富氧环境 → 快速燃烧和放热

如果同时存在挥发、产气、催化或密闭条件，炉压会继续增加，最终可能触发爆裂或炸炉。稳定材料、转开火焰方向或缩小火焰、停止持续灼烧、减少氧气或及时泄压可以打断这条危险链。

##### 4.2.6.5 吸附解毒

带有吸附标签的多孔或矿物材料可以吸附药液中的毒素和杂质：

- 吸附成功时，毒性和丹毒风险降低；
- 吸附材料不会自动分辨好坏，使用不当时也会吸走有效功效；
- 当前吸附材料无法在凝丹前手动取出，吸附物可能被一起炼入丹中；
- 后续可以扩展凝丹前取出吸附材料的操作，但当前不实现；

##### 4.2.6.6 沉淀与净化

某些材料相遇后会生成不再溶于药液的沉淀：

- 如果沉淀主要带走杂质，未来实现分离操作后可以提高成丹纯净程度；
- 如果沉淀带走的是有效药性，则会削弱主功效或产生残丹；
- 当前没有手动分离操作，凝丹时沉淀默认留在炉内，并可能成为丹药中的杂质、特殊成分或药渣；
- 环境温度和投入顺序仍可决定沉淀何时出现，具体手动处理机会以后再扩展。

##### 4.2.6.7 凝胶、黏合与包裹

凝胶和黏合材料吸收水分后，会让药液变得黏稠：

- 适量时可以帮助药液聚集，降低凝丹难度；
- 过早加入会包裹其他材料，使其难以继续提取；
- 过量时会阻碍材料融合，形成外形完整但药性驳杂的丹药；
- 中后期加入通常更适合发挥凝丹作用。

##### 4.2.6.8 浓缩、成核与结晶

凝丹可以借鉴溶液浓缩和结晶过程。药液先经过萃取和蒸发逐渐浓缩，再在合适时机形成结晶核心：

- 药液尚未充分浓缩就凝丹，容易形成松散、功效不足的残丹；
- 浓缩程度合适且存在成核材料时，更容易形成完整丹药；
- 没有成核条件时，药液可能迟迟不成丹，或变成细碎丹砂；
- 凝丹过晚会使药液焦化，并让杂质与有效成分一起凝结；
- 黏合负责“聚在一起”，成核负责“从哪里开始形成丹体”，两者作用不同。

##### 4.2.6.9 寒热冲突与特殊转化

寒凉与炽热相遇时，默认可能互相削弱，也可能因为变化过快产生药性冲突。实际结果取决于当时条件：

- 有稳定但没有催化时，双方更可能缓慢中和；
- 有催化但没有稳定时，冲突更容易突然失控；
- 同时存在稳定、催化和合适的凝丹时机时，可能形成兼具双方特点的隐藏反应；
- 特殊环境或天象可以把原本的冲突改造成冰焰、阴阳交汇等异变候选。

##### 4.2.6.10 腐败、分解与过热损毁

腐败材料在炼制时可能继续分解：

- 低温久放可能使腐化继续扩散；
- 高温可以削弱部分腐败影响，但也可能生成烟毒或新的副产物；
- 极端高温会损毁草木材料，使原有功效大幅减少，并更容易产出废丹或药渣。

#### 4.2.7 投药、火候、环境和天时如何影响反应

材料标签只说明“可能发生什么”，玩家操作与外部条件决定“什么时候发生、发生到什么程度，以及能否被保留”。

##### 4.2.7.1 投药与凝丹时机

- 难溶、厚重的材料通常需要较早投入，给它足够时间提取；
- 挥发、芳香、鲜活的材料通常适合较晚投入，避免长时间受热；
- 催化材料投入越早，影响的反应越多，也越容易让危险提前发生；
- 黏合或成核材料投入过早会妨碍萃取，投入过晚又可能来不及成丹；
- 凝丹过早会锁住没有充分融合的材料；凝丹过晚则可能导致药性流失、杂质析出或药液焦化。

投药顺序不需要为每一组材料单独编写脚本，而应通过材料标签与当前炼制阶段共同判断。

##### 4.2.7.2 火的大小与火的种类

当前萃取玩法中，火焰大小主要表示空间覆盖范围，直接决定能够同时灼烧多少药液精灵珠、药渣精灵珠和杂质精灵珠。火种以及火焰的持续使用仍会影响炉温；火焰大小与炉温的具体换算以后单独确定。

这里的持续时间、久炼和操作窗口通过炼制阶段、短时实时计时、操作节点或内部进度表达，不要求玩家按照现实时间长时间等待。萃取开始后，本炉药效会在三个阶段中随实际操作时间非常缓慢地流失。

| 火种示例 | 反应特点 | 适合与风险 |
| --- | --- | --- |
| 文火 | 温度较低、升温缓慢 | 适合保留挥发和脆弱药性，但处理难溶材料较慢 |
| 武火 | 温度高、升温快 | 适合矿物提取和快速浓缩，也容易烧毁或爆裂 |
| 阳火 | 偏向富氧和氧化 | 有利于净化、氧化和燃烧，不利于怕氧化的药性 |
| 阴火 | 偏向缺氧和还原 | 有利于保存阴性及不稳定成分，也可能保留腐化影响 |
| 灵木火 | 温度较均匀、变化平稳 | 适合长时间融合和稳定控制 |
| 雷火 | 短时间高能、强催化 | 容易触发快速反应、特殊转化和异变 |
| 地火 | 高温并可能带有矿物影响 | 适合厚重矿物，也可能引入杂质或特殊反应 |

##### 4.2.7.3 环境改变反应规则

环境不应只有“某标签增加百分之多少”的效果，而应改变反应是否发生或采用哪种分支。例如：

- 潮湿环境使吸湿、凝胶、水解和腐败更容易发生；
- 干燥环境加快脱水和浓缩，但也可能让挥发性成分更快散失；
- 富氧环境促进氧化与燃烧；缺氧环境保护怕氧化的成分；
- 密闭环境保留挥发成分，同时让炉压和爆裂风险持续积累；
- 寒泉环境使寒凉更容易保留，并改变寒热冲突的结果；
- 瘴气环境可能让挥发物重新污染药液，产生烟毒或腐化反应；
- 灵脉环境可以让原本难以融合的标签进入特殊反应分支。

##### 4.2.7.4 天时提供整炉共同条件

天时不直接指定最后炼出什么丹，而是为所有相关规则提供条件：

- 月相影响阴性、阳性、安神、光敏等标签；
- 节气影响寒热、鲜活、干燥、腐败和材料保存状态；
- 雷暴等特殊天象可以让催化、易燃或金属类材料出现雷性反应；
- 特殊天象只开放相应异变的可能性，不保证必然触发。

#### 4.2.8 任意材料组合的结果与配置量控制

玩家可以自由投入材料，但“任何组合都有结果”不等于“任何组合都能成功炼成一颗新丹药”。系统需要保证每一炉都有能够解释的过程结果：

- 满足某个成丹配置及其过程条件时，形成对应丹药；
- 基本成丹条件满足但过程存在偏差时，可能形成残丹或废丹；
- 没有形成有效结构时，留下药液、药渣或其他未成丹产物；
- 危险反应超过丹炉可以承受的范围时，发生炸炉；
- 满足已有因果条件且触发罕见变化时，形成异丹或异变结果。

丹炉可以承受的范围只表示温度、炉压和危险反应阈值，不代表装料容量；丹炉不设置最大装入量或单炉最大产量。

为了避免材料数量增加后出现组合爆炸，配置应主要分为以下几层：

1. 配置每个标签的名称、分类和说明；
2. 配置每种材料拥有哪些固有标签，以及材料状态会产生哪些状态标签；
3. 配置少量能够反复使用的标签反应规则；
4. 配置需要正式命名和产出的丹药及其匹配条件；
5. 只为少量具有世界观意义的特殊材料组合配置专属或隐藏反应。

例如新增第一百零一种材料时，正常情况下只需要配置这份材料自身的标签。它会自动受到挥发、催化、稳定、易燃、寒热冲突等已有规则影响，而不需要再为它与前一百种材料分别配置一百套反应。

#### 4.2.9 异变必须来自已有因果

异变不能先随机挑选一个结果，再强行编写解释。系统应先检查本炉真正存在的材料、反应历史和外部条件，找出有依据的异变候选，再在这些候选中进行有限随机。

例如“冰焰异变”至少需要具备以下线索：

- 炉内同时存在寒凉与炽热；
- 双方没有在前一阶段完全抵消；
- 存在稳定、催化或其他能够让双方共存的条件；
- 玩家在冲突仍然活跃时进行了凝丹；
- 当前环境或天时允许冰焰类特殊反应出现。

只有满足这些因果条件，冰焰异变才进入候选。随机只负责决定这次是否真正出现，而不是凭空创造完全无关的结果。

系统在本炉炼制期间需要维护触发异变所需的临时过程状态，但不生成独立的炼制历史页面。形成丹药并保存丹方时，丹方记录能够复现结果的关键材料、操作和外部条件；未成丹和炸炉不会保存额外历史记录。为了方便网页版本测试和未来迁移到 Unity，相同输入条件下的随机过程应当可以通过固定随机种子复现。

#### 4.2.10 一炉炼制的完整示例

假设玩家投入以下三种材料：

- **寒潭莲**：寒凉、止血、安神、挥发；
- **赤火草**：炽热、生肌、易燃；
- **白骨粉**：厚重、吸附、成核。

炼制过程可以按照通用规则解释：

1. 玩家先用文火处理寒潭莲。止血与安神相关成分开始进入药液，挥发速度暂时较慢；
2. 玩家加入赤火草。寒凉与炽热开始冲突，赤火草的生肌线索同时进入药液；
3. 玩家加入白骨粉。白骨粉吸附了一部分冲突产生的杂质，并为后续凝丹提供成核条件；
4. 玩家改用武火快速浓缩。赤火草的易燃反应被激活，炉温和危险迅速上升；
5. 因为丹炉保持开放，挥发物及时散出，没有继续积累炉压，因此没有炸炉；
6. 代价是寒潭莲中容易挥发的安神成分也随之流失；
7. 玩家在药液浓度合适时凝丹，白骨粉提供的成核条件使丹体成功形成。

如果上述材料标签、状态、顺序和过程匹配到已经配置的丹药，可以得到类似以下结果：

> 生骨止血丹·中品  
> 主功效：止血  
> 次要功效：生肌  
> 副作用：残留少量骨质杂毒

这一结果不是提前配置“寒潭莲加赤火草加白骨粉必然等于生骨止血丹”的简单公式，而是由材料标签、通用反应和成丹配置共同决定：

- 寒潭莲提供了止血线索；
- 赤火草提供了生肌线索；
- 寒热冲突使双方药性发生改变；
- 白骨粉承担吸附和成核作用；
- 武火让安神成分挥发，因此最终没有形成安神功效；
- 操作没有完全去除白骨粉带来的杂质，因此保留了一项副作用。

如果过程没有匹配到正式丹药配置，系统仍会根据实际情况产出残丹、废丹、药液或药渣；如果玩家在密闭状态下继续使用武火，易燃、挥发和炉压形成危险链，则可能进一步发展为炸炉。

#### 4.2.11 当前讨论进度

用户新增的标签反应与完整炼制过程优先于此前的简化排除项。材料数据边界、标签分类、标签参与匹配、通用反应方向、成丹配置层次、材料状态、隐藏反应因果、完整示例和标签展示范围已经作为当前设计基础。

材料反应主题已经完成，后续讨论转入一炉操作和火候玩法。

#### 4.2.12 材料标签展示

材料 Tips 直接显示该批材料当前拥有的全部标签，包括：

- 药性标签；
- 功效线索标签；
- 反应特性标签；
- 风险标签；
- 状态标签。

每个标签同时显示0～100的当前强度。强度使用进度条表现，进度条的填充颜色按照强度渐变。具体渐变色和界面样式在界面设计阶段确定。

材料标签不需要鉴定，不设置隐藏标签，也不采用使用后逐步解锁标签的机制。状态发生变化时，Tips 中显示的状态标签同步更新。

系统隐藏的是标签之间的完整反应关系、正式丹药的全部成丹条件、隐藏反应条件和异变条件。玩家依据公开标签、炼制过程反馈和实际结果自行探索这些规则。

#### 4.2.13 成丹条件分类与判定顺序

成丹配置不使用统一的匹配百分比。每个成丹配置可以包含以下四类条件：

1. **核心条件**：决定能否成为目标丹药，例如必需材料、必需标签和材料状态；
2. **成形条件**：决定材料能否凝聚成丹，例如最低有效灵液量、黏合或成核条件和凝丹时机；
3. **工艺条件**：包括投入顺序、火候、丹炉状态、环境和天时，用于决定品质、残丹、废丹、副作用和特殊特质等结果分支；
4. **危险条件**：由易燃、挥发、催化、炉压等危险链触发，决定是否发生爆裂或炸炉。

统一判定顺序为：

> 危险条件 → 成形条件 → 丹药核心条件 → 工艺条件与结果分支

具体规则如下：

- 危险程度超过配置限制时，优先判定炸炉，不再继续成丹；
- 未满足成形条件时，产出药液、药渣或其他未成丹产物；
- 满足成形条件和某个丹药的核心条件时，生成对应丹药；
- 核心条件满足但工艺存在偏差时，仍可以生成同种丹药，但可能进入低品质、残丹、废丹、副作用或特殊特质分支；
- 没有匹配正式丹药配置但满足成形条件时，可以匹配配置中的通用残丹或废丹结果。

所有条件、优先级和偏差分支均由配置定义。系统不通过材料属性数值或自动相似度推测结果。

#### 4.2.14 材料比例不参与成丹匹配

成丹配置按照材料标签、材料状态、投入顺序和炼制过程匹配，不设置标准材料比例，也不设置比例允许范围。

- 材料之间的相对数量不作为丹药身份的核心条件；
- 不存在完全比例、近似比例或超出比例容差的判定；
- 材料数量只决定可产生的灵液和掉落物理论上限；
- 将一次已知投料方案中的全部材料数量等量放大时，灵液理论上限相应增加；只有实际收集结果同比增加时，产量才会同比增加；
- 只要所需标签、状态和反应过程仍然成立，改变材料之间的数量关系本身不会改变丹药身份。

#### 4.2.15 标签强度与材料数量

材料使用已经确定的五类标签。真正影响丹药功效或炼制反应的标签可以带有配置强度，该强度属于材料所提供的标签，不是独立的材料属性数值。

- 重复投入具有同一个标签的相同材料，不会累加或提高该标签的强度；
- 增加相同材料只增加可萃取灵液的理论上限，不提高标签强度；
- 例如重复投入带有“引兽”标签的相同材料，不会使引兽效果变强；
- 不同材料提供同名标签时如何选择最终强度，后续继续确定。

#### 4.2.16 标签强度范围与 Tips 表现

五类标签统一使用0～100的强度范围，不采用“微弱、普通、强烈”等离散档位。

- 0表示当前标签没有实际作用；
- 100表示当前配置范围内该标签达到最高强度；
- 标签强度直接参与成丹条件、通用反应、隐藏反应、环境、天时和异变规则匹配；
- 重复投入具有同名标签的材料时，标签强度不相加；
- 材料 Tips 在标签旁显示0～100的渐变色进度条；
- 渐变色的具体颜色、方向、动画和视觉样式以后统一设计。

#### 4.2.17 同名标签的强度合并

不同材料在同一炉中提供同名标签时，默认采用其中最高的标签强度，不进行相加或平均。

例如材料甲提供“引兽40”，材料乙提供“引兽80”，则本炉用于规则匹配的引兽基础强度为80。

- 重复投入相同材料不会提高同名标签强度；
- 投入多种具有同名标签的材料也不会累加强度；
- 所有投入材料都可以产生对应掉落物，但只有实际收集到的有效灵液计入成丹数量；
- 火候、环境、天时和反应规则可以在合并后的基础强度上继续产生变化；
- 特殊协同或隐藏反应可以通过明确配置覆盖“默认取最高值”的规则。

#### 4.2.18 反应规则与标签强度变化

通用反应章节负责定义反应的触发条件、因果方向和可能结果，例如中和会减弱腐蚀、挥发会导致相关功效流失、寒热可能互相削弱或形成特殊转化。

系统不为所有反应制定统一的标签强度加减公式。每条反应规则自行配置触发后相关标签的目标强度或变化量，并将最终结果限制在0～100范围内。

该规则避免把不同性质的反应强行套入同一个数值公式，同时保留统一、配置化的规则执行结构。

#### 4.2.19 第二项完成状态

材料反应所需的材料数据、五类标签、标签强度、同名标签合并、标签展示、通用反应、成丹条件、异变因果和数值配置边界均已确定。第二项“材料反应”完成。

#### 4.2.20 萃取后的有效输入

萃取玩法确定后，材料反应的实际输入边界调整为：原始材料以可局部溶解的纯平面多边形素材存在，并在丹炉上方按配置化显式槽位互不重叠地排布；火焰固定从下方向上灼烧，实际接触位置按照隐藏成分分布图逐步转化为药液精灵珠、药渣精灵珠和杂质精灵珠；融合与凝丹只读取玩家在萃取阶段实际收集到的内容。

- 每种材料通过配置定义可能产生的灵液类型、对应标签和强度；
- 药渣与杂质同样由材料及其当前状态配置产生；
- 每种材料通过配置提供可见外形和对应的隐藏成分分布图；
- 规则层使用低分辨率逻辑网格，把药材内部位置标记为药液、药渣、杂质或空白；
- 当前原型采用双图片资源：透明背景的药材外观图和坐标对应的隐藏成分图；
- 成分图默认使用64×64逻辑分辨率，透明代表空白，青绿色代表药液，灰色代表药渣，紫黑色代表杂质；
- 外观图可以使用更高分辨率，程序通过归一化坐标把外观图的溶解位置映射到成分图格子；
- 成分图只供规则计算，不在正常游戏中显示；
- 资源加载时校验成分图尺寸、允许颜色、非空区域和坐标映射；
- 首版使用8种可替换的正常命名测试药材外观图与人工绘制的成分色块图；
- 火焰只溶解自下而上实际接触到的位置，不能越过下方素材直接灼烧被遮挡的上层位置；被溶解部分按照该位置的成分类型进入对应累计量；
- 某类累计量达到标准精灵珠体积时，在最近的实际溶解位置生成对应精灵珠；
- 药材完全溶解时，剩余不足一颗标准体积的成分生成按比例缩小的精灵珠；
- 药材尚未溶解的多边形面积直接表现剩余萃取进度，完全溶解后表示该材料萃取完成；
- 相同状态的同种材料按投入份数增加理论产出，基础总量不受随机影响；
- 理论产出由成分分布图和标准精灵珠体积计算，不再单独配置固定波次或另一份理论总量；
- 每份标准药材的三类精灵珠目标总数约为300颗，基准为药液精灵珠约75颗、药渣精灵珠约180颗、杂质精灵珠约45颗；
- 药液精灵珠通常保持在70～80颗，不同材料可以通过成分分布图调整具体比例；
- 系统根据成分图全部非空成分量和目标总珠数，自动换算一颗标准精灵珠对应的成分量；
- 相同材料投入多份时，三类精灵珠数量和目标总量按份数增加；
- 同一种材料的主体成分分布保持固定，当前随机只轻微改变区域边缘、珠子生成位置和初始速度；
- 反应特性标签和状态标签如何分别改变成分分布和掉落模式暂不细化，作为后续扩展保留；
- 被火焰烧毁、没有接住或掉出场景的对象不会进入后续反应；
- 收集到的灵液决定后续可用标签、功效线索和有效药量；
- 收集到的药渣和杂质作为污染输入，参与品质、副作用、残丹和废丹判定；
- 多种药液精灵珠之间的融合、排斥、争斗和轨迹变化由标签与专用规则配置驱动。

原始材料标签仍负责生成和解释萃取内容，但不能绕过玩家的实际灼烧和接液结果，直接进入融合或成丹计算。

### 5.2 已确认结论

#### 5.2.1 场景布局与开炉流程

炼丹直接在游戏场景中进行，不进入独立的表格式炼丹界面。丹炉作为场景对象放置在当前场景中，当前场景同时提供本次炼制所处的环境条件。

基础布局如下：

- 丹炉位于场景中的主要操作区域；
- 玩家背包位于屏幕下方；
- 玩家从背包中选择本炉准备使用的药材；
- 已选择但尚未投入的药材悬浮陈列在丹炉两侧；
- 材料仍可通过 Tips 查看全部五类标签及0～100强度。

开炉顺序如下：

1. 玩家从屏幕下方的背包选择准备使用的药材；
2. 选中的药材悬浮到丹炉两侧，作为待投入材料；
3. 玩家选择火种；
4. 选择火种后只装备火种，不会自动喷火或加热；
5. 玩家按住鼠标左键喷火，丹炉开始加热并产生实际温度；松开左键立即停火；
6. 玩家可以观察并调控温度；
7. 玩家根据当前温度和炼制反馈，自行选择合适时机投入第一份及后续材料。

系统不设置单独的“预热”步骤或预热按钮。尚未投入材料时，丹炉仍可以在火种作用下升温，玩家可以等待温度达到需要的范围后再投药。

#### 5.2.2 炼制过程中的补选与投药

屏幕下方的背包在加热和炼制过程中持续可用。玩家不需要在选择火种前确定本炉使用的全部材料，可以根据温度、药液、气味、炉声、炉压等反馈临时补选药材。

- 炼制中途从背包选中的材料继续悬浮到丹炉两侧；
- 左键点击背包药材一次预选一份，连续左键点击可以增加待投数量；
- 悬浮材料属于待投入状态，暂时占用对应背包库存，但尚未真正消耗；
- 当前原型只使用鼠标点击投药，不提供数字快捷键；
- 玩家左键点击某个悬浮材料时，每次只投入一份，材料进入丹炉上方的萃取区域；
- 玩家右键点击某个悬浮材料时，每次取消一份并归还背包；不设置额外取消按钮；
- 同种悬浮材料有多份时显示剩余数量，每次投入后数量减一；
- 悬浮材料点击优先于喷火，该次点击只执行投药，不会同时点燃火焰；正在喷火时需要先松开左键，再移动到悬浮材料处点击投入；
- 炼丹操作区禁用浏览器默认右键菜单，右键只执行当前配置的游戏交互；
- 已投入丹炉的材料立即消耗，不能撤回；
- 系统记录材料投入顺序、投入时机、当时温度，以及后续灼烧和接液操作，供成丹匹配及丹方保存；
- 只有萃取阶段允许继续选择和投入药材；进入融合后停止继续投药。

#### 5.2.3 材料状态范围

材料不设置研磨、浸润、发酵、炭化等处理或反应状态标签，炼丹场景也不提供对应的材料加工操作。

状态标签只保留：

- **保存状态**：新鲜、干燥、腐败、冰封；
- **生长来源**：野生、种植、变异；
- **年份**：根据材料实际年份生成对应标签。

#### 5.2.4 丹炉开放、密闭和泄压

丹炉开放、密闭、炉压和泄压概念暂时保留，继续作为挥发、爆裂和炸炉等反应的候选条件。

当前不确定炉盖、泄压口、炉压控制等具体交互，也不将这些复杂操作作为开始制作所必需的流程。相关操作方式、反馈和丹方记录要求延后讨论。

#### 5.2.5 三阶段推进

萃取、融合和凝丹是玩家控制火候的三个关键阶段，由玩家主动推进，系统不自动替玩家切换。

统一流程为：

> 萃取 → 融合 → 凝丹

具体规则如下：

- 第一份材料投入后，自动进入萃取阶段；
- 玩家在萃取阶段按住或松开鼠标左键控制喷火，调整火焰方向与大小、控制接液容器并继续投药，同时观察炉温；
- 萃取区域内只要还有任何未完全溶解的药材，就不能完成萃取；
- 所有已投入药材完全溶解后，如果场景中仍有精灵珠正在下落、移动或互动，仍不能完成萃取；
- 只有三类精灵珠全部被接住、烧毁或落空，完成本轮结算后，玩家才能主动进入融合阶段；
- 进入融合后不能返回萃取，也不能继续投入材料；
- 玩家自行判断时机并主动开始凝丹；
- 进入凝丹后不能继续投药，也不能返回融合；
- 三个阶段中都可以继续调控温度；
- 投入第一份材料时启动萃取阶段计时；萃取没有固定总时限，未来接入融合与凝丹后分别记录三个阶段的用时；
- 本炉药效保留率从100%开始随操作时间非常缓慢地下降，直到凝丹结束；
- 阶段切换时机、各阶段用时、温度变化和材料投入时机均参与最终结果计算，并由丹方记录。

#### 5.2.6 沉淀和吸附材料分离

沉淀分离以及凝丹前取出吸附材料的概念暂时保留，但当前不提供捞取、过滤或其他手动分离操作。

- 沉淀和吸附材料默认留在丹炉中；
- 凝丹时，它们可能成为副作用、特殊成分、废丹原因或药渣；
- 玩家当前只能通过其他材料、火候和凝丹时机影响相关结果；
- 手动分离的具体操作和收益延后讨论。

#### 5.2.7 凝丹与本炉结束

玩家主动进入凝丹的时刻就是凝丹时机。凝丹开始后由系统根据当前反应状态自动完成本炉，不再增加“完成凝丹”按钮或独立收丹操作。

- 凝丹阶段继续保持不可投药状态；
- 玩家仍然可以调控温度，凝丹阶段的火候继续参与结果判定；
- 丹药通过药液聚拢、丹光、炉声等表现逐渐成形；
- 达到成丹条件后，系统自动结束本炉；
- 凝丹阶段火候错误时，可以形成残丹、废丹、药渣或触发炸炉；
- 成丹时丹药从丹炉飞出，未成丹时药渣等产物从丹炉飞出；
- 炸炉时全部投入材料转化为数量较少的可回收药渣；
- 所有产物继续通过鼠标悬停 Tips 显示完整信息。

#### 5.2.8 丹方自动生成

只要本炉实际形成了丹药，系统就自动将本炉关键条件保存为丹方，不要求玩家从丹药 Tips 中手动保存。

- 正常丹、残丹、废丹和异丹均自动生成丹方；
- 未成丹、药渣和炸炉不生成丹方；
- 丹方记录本炉材料、材料状态、投入顺序、萃取阶段中的投入时机、温度变化、阶段切换、三个阶段的实际用时、药效保留率、火焰方向轨迹、火焰大小变化、接液容器移动轨迹和实际收集结果等复现条件；
- 异变丹药生成的丹方名称仍不增加“异变”二字；
- 已存在同名丹方时如何保存不同炼制过程，在丹方机制主题中继续讨论。

#### 5.2.9 第三项完成状态

一炉炼制已经形成“场景选材 → 选择火种 → 控火灼烧并接取灵液 → 主动推进萃取、融合、凝丹 → 系统自动结束 → 产物飞出 → 成丹时自动生成丹方”的完整操作闭环。

丹炉开放、密闭、炉压、泄压、沉淀分离和吸附材料取出作为后续扩展保留，不阻塞当前流程。丹方快速炼制时自动复现哪些操作，统一放到丹方机制主题中确定。

#### 5.2.10 萃取阶段详细操作

萃取阶段由“上层控火筛选”和“下层移动容器收集”两部分共同组成。玩家需要同时操作火焰和接液容器，把有效灵液送入后续融合阶段，并尽量排除药渣与杂质。

##### 5.2.10.1 药材准备与摆放

- 玩家可以选择一种或多种药材同时参与本次萃取；
- 从背包选中的药材先悬浮在丹炉两侧；
- 当前只通过鼠标进行选材、投药和取消，不设置数字快捷键或额外取消按钮；
- 左键点击背包药材预选一份；左键点击悬浮药材投入一份；右键点击悬浮药材取消一份并归还背包；
- 同种待投药材有多份时显示并扣减剩余数量；
- 点击待投药材时不触发喷火；
- 正式投入后，药材进入丹炉上方的萃取区域；
- 多种药材可以同时处于萃取区域，也可以由玩家分批投入；
- 药材统一使用纯平面的多边形素材，由系统在丹炉上方按投药顺序分配配置化显式槽位，不允许玩家自由拖放；
- 任意两份药材的权威 OBB 内部不得相交，精确边缘或角点接触允许；
- 槽位中心与旋转由配置逐项给出，同一炉内已分配槽位不复用；
- 相同种类、相同保存状态、生长来源和年份的多份药材按照份数各占一个独立槽位；
- 每份素材使用自己的成分分布图层，总溶解量、所需时间和理论精灵珠产出均按份数增加；
- 药材溶解后不掉落、不坍塌也不重新排列，剩余部分保持原位置；
- 正式配置提供覆盖全部24份库存的槽位，配置槽位少于库存总份数时拒绝启动；
- 火焰固定从药材摆放区下方向上灼烧，不能穿过下方素材直接命中其正后方的上方素材；
- 火焰碰到下层素材后会像水流绕过柱子一样沿轮廓分向左右两侧，并从两侧继续向上；下层素材烧出缺口后，火焰也可以沿缺口继续向上；
- 火焰方向决定主要流动方向，火焰大小决定初始火流宽度；
- 同时萃取哪些药材以及投入顺序，会影响精灵珠密度、药液精灵珠互动和玩家控火难度；
- 自由摆放药材作为后续扩展保留，不进入当前基本版本。

##### 5.2.10.2 灼烧与掉落物

玩家使用丹炉下方的火焰向上灼烧药材摆放区。药材使用可局部溶解的纯平面多边形素材表现；只有火路自下而上实际接触到的位置才会逐渐透明并从本体上消失，被下方素材遮挡的上方位置不会直接受热。被溶解部分按照隐藏成分分布图转化为三类小型精灵珠并向下掉落：

1. **药液精灵珠**：有效成分，进入收集容器后成为融合与凝丹的主要原料；
2. **药渣精灵珠**：无效或低价值残留，进入容器后会影响后续结果；
3. **杂质精灵珠**：对品质和副作用影响更明显的污染物。

三类对象都使用较小、可移动的精灵珠表现。药液精灵珠以水滴精灵为主要视觉语言；药渣精灵珠和杂质精灵珠采用类似病毒、异物或污染颗粒的轮廓，使玩家能快速区分。

具体辨识规则如下：

- 药液精灵珠使用半透明水滴轮廓、柔和内发光和简单表情，颜色由来源药材配置，移动时轻微游动，受伤时连续缩小；
- 药渣精灵珠使用深褐或灰黑色不规则结块轮廓、粗糙表面和裂纹，移动时翻滚，受伤时逐渐开裂、掉屑并缩小；
- 杂质精灵珠使用紫黑或暗绿色尖刺、病毒或污染颗粒轮廓，带少量烟气和细小抖动，受伤时收缩、冒烟并消散；
- 三类精灵珠必须同时依靠轮廓、纹理、运动和受伤表现区分，不能只依靠颜色；
- 颜色、纹理、动画速度、粒子效果和声音组全部走配置；
- 首版使用轮廓明确的可替换测试图形验证辨识度，但仍完整实现已经确认的动画、粒子和声音表现。

不同药材转化出的药液精灵珠需要具有不同颜色、形态、纹理或特效，玩家能够识别它来自哪种药材。

每种药材配置一张与可见多边形外形对应的隐藏成分分布图。规则层使用低分辨率逻辑网格标记药液、药渣、杂质和空白位置，表现层使用平滑溶解遮罩。规则层先根据二维火流判断当前能够接触的暴露位置，再按以下方式溶解：

- 每份药材独立计算本帧总溶解量；
- 只要一份药材至少有一个位置接触实际火流，本帧总溶解量就等于统一基础溶解速度乘以本帧时长；炉温、正面位置和绕流位置都不提供额外强度倍率；
- 没有任何位置接触火流时，本帧总溶解量为零；
- 系统沿火焰法向把材料划分为配置化前沿通道，每条通道只允许最靠近火源的剩余格进入候选；未完成格通过显式 fire-front 状态在后续 tick 继续扣减，不使用 `remaining < initial` 推断，以免自然损耗污染；
- 小范围接触只开放少量通道，按相对深度持续烧出深而连通的缺口；大范围接触开放更多通道，先形成更宽、较浅的溶解面；
- 火焰大小只改变覆盖范围，不直接或间接增加单份药材的总溶解量；
- 火流同时接触多份药材时，每份药材分别计算并行溶解；
- 基础溶解速度与前沿通道宽度均配置化；当前 `frontLaneWidthCells = 1`。

当前使用双图片配置：药材外观图负责场景显示，64×64隐藏成分图负责规则采样。成分图颜色固定为透明空白、青绿色药液、灰色药渣和紫黑色杂质；外观图与成分图使用相同的归一化坐标。加载材料时必须验证资源尺寸、颜色和非空区域。

系统分别累计三类溶解成分。某类累计量达到一颗标准精灵珠体积时，在最近的实际溶解位置生成对应精灵珠；药材完全溶解时，剩余不足完整一颗的成分生成按比例缩小的精灵珠。理论产出直接由成分分布图与标准精灵珠体积计算。

药材本体尚未溶解的多边形面积就是萃取进度的视觉反馈，不额外显示萃取进度条。药材完全溶解后，该份材料萃取完成。

进入融合必须同时满足两个条件：

1. 萃取区域中的所有药材多边形素材已经完全溶解；
2. 场景中的药液精灵珠、药渣精灵珠和杂质精灵珠已经全部被接住、烧毁或落空。

只要还有精灵珠正在下落、移动或互动，系统就继续禁止进入融合。两个条件全部满足后才解除限制；进入融合后不再允许投入新药材。

同一种药材的主体成分分布保持固定，让玩家能够学习不同位置的内容。当前只对分布区域边缘、精灵珠生成位置和初始速度做轻微随机，不完全打乱主体分布。易挥发、坚韧、爆裂、黏稠等标签化差异暂不制作，后续再逐项扩展。

精灵珠的基础空中运动规则如下：

- 精灵珠从实际溶解位置生成；
- 生成时获得配置范围内的水平初速度和向下初速度；
- 生成后受到重力影响，并受最大下落速度限制；
- 使用轻微的水平漂移表现生命感；
- 火源上方属于灼烧区；珠子向下越过火源高度后进入安全接取区；
- 进入安全接取区的珠子立即停止参与火流阻挡，不再受到火焰伤害或火焰推力，但继续受重力、基础运动和配置化精灵珠互动影响；
- 界面不绘制额外分界线，火源本身作为灼烧区与安全接取区的自然分界；
- 碰到丹炉左右内壁时按照配置的衰减系数反弹；
- 三类精灵珠都会与药材当前尚未溶解的多边形区域发生实体碰撞，不能穿过药材；
- 珠子碰到药材后根据碰撞方向轻微反弹，并沿药材轮廓滚落、滑落或暂时停留；
- 上层药材产生的珠子可以被下层药材挡住，玩家烧出缺口或使用火焰推力后才能改变其路线；
- 药材格子完全溶解后，该位置同时失去挡珠碰撞，珠子可以从缺口通过；
- 从接液容器两侧落出底部边界时判定落空；
- 落空时仍有剩余体积的珠子按照类型和剩余体积进入炉底药渣池；已经烧掉的体积不计入，只触发护盾但未实际缩小的珠子按100%计入，完全烧毁的珠子不进入；
- 精灵珠当前大小影响碰撞范围，但不改变基础下落速度；
- 珠子被烧小后可以通过更窄的缺口；
- 基础版本不让所有精灵珠互相进行刚体碰撞；
- 融合、排斥和争斗等行为使用独立的邻近互动规则，只查询附近且符合配置条件的对象；
- 三类珠子当前共用相同的基础药材碰撞规则；
- 水平初速度、向下初速度、重力、最大下落速度、水平漂移、墙壁及药材反弹衰减、表面摩擦、滑动速度和碰撞半径倍率全部走配置。

##### 5.2.10.3 火焰操作

- 玩家选择火种后只装备火种，不会自动喷火或加热；
- 当前火源固定在丹炉内部中间、接液容器轨道上方，不跟随鼠标移动；
- 火源显示小型喷火口或火种核心，明确标示火流起点；
- 玩家通过鼠标移动控制火焰目标方向；
- 火焰只能在朝上的扇形范围内喷射，默认允许从左上到右上约140°；鼠标超出范围时，目标方向夹到最近的边界；
- 火源位置、允许角度和火焰起始宽度全部配置化，试玩后可以直接调整；
- 玩家按住鼠标左键时持续喷火，松开左键时立即关闭实际火流；
- 火焰根部快速而平滑地追随目标方向，上半部分稍微滞后并弯曲，默认转向平滑时间约为0.1秒；
- 快速转开或松开左键后可以保留极短的余焰消散表现，但余焰不产生溶解、伤害或推力；
- 玩家可以通过鼠标滚轮或界面滑动条控制同一个火焰大小数值，两种输入双向同步；
- 当前所说的火焰大小主要表示灼烧范围，而不是一个独立的伤害或属性点数；
- 药材只有处于实际火流中、并且能够被火流接触到的位置才会持续溶解；火焰转开后立即停止溶解，但已有溶解结果保留；
- 单份药材只要有任意位置接触实际火流，就使用统一基础速度溶解；炉温、正面位置和绕流位置不提供强度倍率；
- 火焰大小只决定初始火流宽度，不直接或间接提高单份药材的总溶解速度；
- 小范围火流将溶解量集中到少量位置，大范围火流将同一份溶解量分散到更多位置；
- 火流同时接触多份暴露药材时，多份药材并行溶解并产生更密集的精灵珠；
- 火焰会被未溶解药材以及药液精灵珠、药渣精灵珠、杂质精灵珠阻挡，不穿透任何一种对象；
- 丹炉操作区域使用一张不可见的低分辨率二维流场网格，火源向网格持续注入流动方向和可到达区域；
- 药材当前剩余形状和所有精灵珠每次模拟更新时写入流场，作为动态障碍；
- 每个流场格子的阻挡值使用0～1连续值，而不是只使用阻挡或不阻挡两种状态；
- 药材尚未完全溶解的成分格按完全阻挡处理，格子完全溶解后才移除该位置障碍；
- 单颗精灵珠按照圆形轮廓实际覆盖流场格子的面积写入部分阻挡，一颗珠子可以同时影响相邻多个格子；
- 多颗精灵珠覆盖同一格时累加阻挡值并限制到1，因此密集珠群能够形成明显挡火区；
- 珠子缩小时覆盖面积和阻挡值同步降低，完全消失后立即移除障碍；
- 三类精灵珠当前使用相同的流场阻挡换算规则；
- 火流碰到对象后，中间与实体轮廓重合的部分被截断，并沿对象轮廓分向左右两侧继续向上；
- 对象正后方在火焰尚未绕到前不会被灼烧，左右两侧火流绕过对象后可以逐渐汇合；绕流后的火焰与正面火焰强度相同；
- 药材烧出缺口，或者挡路的精灵珠移动、缩小、消失后，原本被遮挡的位置可以重新形成火流；
- 火焰画面与实际伤害、溶解判断共用同一份火流结果，不出现画面绕开但规则仍穿透的情况；
- 流场默认每秒更新30次，60帧画面在相邻模拟状态之间平滑插值；
- 流场分辨率、更新频率、扩散程度、绕流强度、汇合速度和障碍覆盖换算全部配置化；
- 当前不模拟氧气、烟气和燃烧化学；
- 精灵珠用于挡火的范围随其剩余体积和可见尺寸同步缩小；
- 药材多边形位置固定，不受火焰推动；
- 三类精灵珠只要位于火流可到达区域，就按照当前位置的火流方向受到统一基础推力，可以减缓下落、向上吹起或推向左右两侧；
- 珠子剩余体积越小，越容易被火流推动；
- 首次接触火焰的保护时间只延迟灼烧伤害，不阻止推力生效；
- 火焰大小滑动条附近增加临时“火焰推力”开关，默认开启，炼制过程中可以即时切换；
- 关闭开关后只停止继续施加火焰推力，不清除珠子已经获得的速度；
- 推力强度、速度上限、体积影响曲线以及三类精灵珠的受力倍率均通过配置调整；
- “火焰推力”开关当前用于网页原型试玩对比，是否进入正式界面以后再决定；
- 当前所有药材共用一套可配置的基础溶解速度和受火位置平均分配规则，不制作耐火、难溶等材料差异；
- 火焰可以灼烧并消灭三类精灵珠；
- 精灵珠首次接触火焰时出现一层淡淡的护盾，并发出“咿咿呀呀”的声音；
- 大量精灵珠在同一时间窗口内触发叫声时合并音效事件，不为每颗珠子叠加独立音轨；
- 合并音效根据触发数量调整音量、热闹程度或音高变化；音效合并窗口、最大同时播放数和音量范围全部走配置；
- 默认连续接触火焰超过0.5秒后才开始受到灼烧伤害，首次接触保护时间支持配置；
- 药液精灵珠受到持续灼烧伤害后逐渐变小，最后完全消失；从开始受伤到消失的时间支持配置；
- 精灵珠一旦移出火焰就立即重置首次接触保护计时，不设置离火等待时间；
- 是否允许离火后重置保护支持配置；
- 允许重置时，再次接触火焰会重新触发护盾，但已经缩小的体积不会恢复；
- 不允许重置时，精灵珠再次接触火焰会沿用此前的接触和受伤状态；
- 三类精灵珠共用接触保护与持续灼烧逻辑；药液珠持续缩小，药渣珠出现裂纹、掉屑和碎裂，杂质珠收缩、冒出少量烟气并消散；相关持续时间、粒子和声音参数均可配置；
- 每颗精灵珠内部记录初始为100%的剩余体积；
- 灼烧同时减少精灵珠的视觉大小和可贡献数量，完全缩小后消失；
- 接入容器的精灵珠按照当前剩余体积贡献有效药液量、药渣污染量或杂质污染量；
- 灼烧只减少数量，不改变精灵珠携带的标签和标签强度；
- 剩余体积不显示数字或进度条，只通过精灵珠大小表现；
- 容器累计各颗精灵珠贡献的小数数量，最终按照实际有效药液总量计算成丹数量；
- 玩家需要烧掉不希望进入容器的药渣精灵珠和杂质精灵珠，同时避免误烧药液精灵珠；
- 当一批密集药渣精灵珠突然掉落时，玩家可能需要临时增大火焰进行清除；
- 如果范围过小，药渣精灵珠可能穿过火焰并遮挡或干扰随后掉落的药液精灵珠；
- 如果火焰过大或方向不准，也可能把紧随其后的药液精灵珠一起烧掉。

##### 5.2.10.4 接液容器操作

- 丹炉底部放置一个类似小碗或碟子的接液容器；
- 接液容器位于火源下方的安全接取区内，容器本身和已经接取的珠子不参与火流阻挡；
- 玩家按住 `A` 或 `D` 时，容器经过短暂加速向对应方向移动；
- 松开按键或同时按住 `A`、`D` 时，容器减速停止；
- 改按相反方向时，容器先减速再反向；
- 容器只能在丹炉底部的水平轨道内移动，碰到边界后直接停止，不反弹；
- 容器速度不受已接取珠子数量影响，不设置负重；
- 容器上方具有一个随容器移动的简单接取区域；
- 精灵珠中心进入接取区域后立即判定接取成功，不模拟复杂的碗沿刚体碰撞；
- 玩家需要移动容器接住希望保留的药液精灵珠；
- 没有接住的药液精灵珠视为浪费，不进入后续融合与凝丹；
- 接住药渣精灵珠或杂质精灵珠时，这些污染物进入后续流程，并可能降低丹药品质、增加副作用或导致废丹；
- 精灵珠碰到容器内部后立即判定为接取成功，退出下落、火焰碰撞和精灵珠互动；
- 接取成功的精灵珠继续保持自身形态、标签、强度和接取时的剩余体积；
- 药液精灵珠在容器内漂浮和轻微游动，药渣精灵珠与杂质精灵珠更靠近容器底部；
- 容器不显示数量文字，玩家通过精灵珠的数量、大小和拥挤程度观察收集结果；
- 当前不设置接液容器容量限制；
- 接取后的精灵珠只保留轻量漂浮、游动或沉底动画，不再执行复杂的相互物理碰撞，以支持数百至数千颗珠子的显示；
- 已接取的精灵珠跟随容器移动；
- 容器最大速度、加速度、减速度、反向速度、移动边界以及接取区域宽度和高度全部走配置；
- 未来实现融合阶段时，容器中的全部精灵珠统一飞入中央融合区域并继续参与后续互动；当前萃取原型不执行这一步；
- 当前只使用一种基础接液容器；不同丹炉拥有不同容器范围、速度或特殊能力的设计作为后续扩展保留。

##### 5.2.10.5 药液精灵珠互动

药液精灵珠不是只做垂直掉落的静态物体。来自同时投入的一种或多种药材的药液精灵珠，可以根据配置发生互动：

- 相互靠近或融合；
- 相互排斥、争斗或改变移动方向；
- 保护、追逐或阻挡其他掉落物；
- 因互动改变下落速度和轨迹，从而提高玩家控火与接液难度。

互动规则由灵液对应的材料标签和专用配置决定，不写死在表现代码中。具体互动类型、触发条件和强度以后逐项设计。

当前萃取原型只实现一个用于验证框架的基础争斗案例：

- 在8种测试材料中配置一对互相冲突的药液精灵珠；
- 灼烧区和安全接取区都允许触发新的争斗，区域切换不终止正在进行的互动；
- 珠子被接住、烧毁或落空后才退出互动模拟；
- 两种珠子进入邻近范围后，播放短暂争斗动画和声音；
- 两者互相撞击、改变下落方向并随后弹开；
- 争斗不减少体积、不改变标签，也不触发融合；
- 每颗珠子同一时间只能参与一次互动，并具有配置化冷却时间；
- 未配置关系的精灵珠相互穿过；
- 触发材料或标签、邻近距离、持续时间、弹开力量、冷却时间、动画和声音全部走配置；
- 系统使用空间网格查询附近对象，不遍历场景中的全部精灵珠；
- 吸引、融合、保护和追逐作为后续互动类型保留。

##### 5.2.10.6 萃取结果如何进入后续阶段

进入融合阶段的不是原始投入材料，而是玩家实际接入容器的内容：

- 收集到的灵液种类、标签、强度和数量；
- 误接入的药渣数量；
- 误接入的杂质种类和数量。

这些内容在萃取结束前继续以精灵珠形态留在接液容器中。未来实现融合阶段后，系统再将它们统一转移到中央融合区域，不重新生成或重置其剩余体积；当前萃取原型在容器中直接结束流程。

被火烧毁、没有接住或掉出场景的灵液不参与后续融合与成丹输入。从容器两侧落空且仍有剩余体积的三类珠子按照剩余体积进入炉底药渣池，未来成功成丹时统一作为药渣产出；其中药液珠的剩余体积仍计入药液流失，已经烧掉的药液体积在灼烧发生时就立即计入流失。收集到的有效灵液影响可形成的丹药、功效和数量；接入容器的药渣与杂质影响品质、副作用、残丹和废丹分支。

##### 5.2.10.7 火种未来能力

不同火种未来可以拥有针对萃取玩法的特殊能力，例如：

- 更快灼烧药渣精灵珠和杂质精灵珠；
- 精准保护某些特定药液精灵珠；
- 自动追踪药渣精灵珠、杂质精灵珠或其他指定目标。

这些火种能力当前只保留为扩展方向，暂不进入基本版本。

#### 5.2.11 阶段计时与药效流失

- 第一份材料开始萃取时，萃取阶段计时从零开始；尚未投药时的试火和升温不计时；
- 当前萃取原型没有固定总时限；未来接入融合和凝丹后，三个阶段分别记录用时；
- 系统同时记录总用时和三个阶段各自的用时；
- 本炉药效保留率从100%开始，以非常缓慢的速度持续下降，直到凝丹结束；
- 当前使用统一的固定自然流失速度，不为不同材料制作复杂的独立流失规则；首版参考值为每分钟约1%；
- 炉温暂时不影响药液自然流失；温度影响流失的机制保留为未来不同丹炉的可选特点；
- 药液精灵珠被实际烧掉的体积立即计入本炉药液流失；落空时按照剩余体积继续计入流失；已经接入容器的剩余药液不再流失；
- 药渣和杂质不计入药液流失，只累计污染并影响后续品质；
- 药液流失率的分母是全部已投入药材的理论药液总体积，分子是累计自然蒸发、实际烧掉和落空的药液体积；最终比例限制在0%～100%；
- 自然流失每分钟扣除当前暴露有效药液的约1%；暴露药液包括未溶解药材中尚存的药液和场上活动药液珠，不包括已经接入容器的药液；
- 中途追加理论药液体积为`V`的新材料时，若当前流失率为`R`，理论总量增加`V`的同时，累计流失量增加`V × R`，因此追加前后的流失率保持不变；
- 当前版本中途追加药材时，新材料继承本炉当前流失比例，不会降低、稀释或恢复已经累计的流失；
- 允许追加药材降低流失率的“添药救炉”方案只作为后续扩展保留，当前不实现；
- 药效保留率直接修正最终主功效、次要功效和适用的特殊效果数值，不作为新的丹药属性显示；
- 时间流失不直接改变丹药种类、成丹数量和品质，也不单独导致炼制失败；
- 本炉药液累计流失超过70%时属于例外：本轮萃取立即失败并停止火焰、计时与所有操作；所有未溶解药材、场上精灵珠和容器内容全部转化为药渣；
- 系统不设置要求玩家等待很久的制作时间，也不设置固定的萃取总时限；玩家没有持续灼烧时，一轮操作进行6～7分钟属于正常情况；
- 新手能够以较慢速度完成完整操作，熟练玩家则能通过缩短操作时间保留更多药效；
- 界面不显示阶段计时、总计时、药效保留率或对应进度条；
- 药效流失只使用纯视觉反馈：少量药液从当前炼制物中向上飘散，到达或接近丹炉壁后化为蒸汽；
- 药液逸散的频率和实际药效流失速度都很慢，不营造强制倒计时感；
- 药液流失达到50%时，蒸汽明显增多且药液颜色开始变淡；达到65%时，蒸发明显加剧，场上药液精灵珠表现出慌张或虚弱；
- 两级警告的阈值和表现强度均可配置，界面仍不显示精确流失百分比；
- 向上飘散的药液只是视觉表现，不是第四种掉落物，玩家不能接取，也不参与火焰灼烧和后续反应。

系统仍在内部记录用时和药效保留率，用于最终功效计算和丹方复现。

#### 5.2.12 当前萃取原型的开始、结束与重开

当前网页原型使用以下临时流程：

> 选材待机 → 加热待投药 → 萃取进行中 → 可以结束萃取 → 萃取完成

- 初始场景显示丹炉、背包和火种选择；
- 选择当前唯一火种后只装备火种，不会自动喷火或加热；火焰大小使用可配置初始值，默认建议为30；
- 尚未投入药材时可以按住鼠标左键喷火、调节火焰和等待升温，但不开始萃取计时与药效流失；
- 投入第一份药材后正式进入萃取，并开始内部计时和药效流失；萃取没有固定总时限；
- 萃取过程中可以继续从背包选择并投入材料；
- 所有已投入药材完全溶解且所有空中精灵珠完成结算后，临时“结束萃取”按钮变为可用；
- 系统不自动结束，玩家可以继续投药，也可以主动点击按钮；
- 点击“结束萃取”后停止火焰、计时和场景模拟，并显示临时“萃取完成”弹板；
- 药液累计流失超过70%时，不再等待正常完成条件，本轮立即停火、停止计时并禁用操作；
- 未溶解药材迅速焦黑碎裂，场上三类精灵珠和容器内容失去原本颜色并化为药渣颗粒；全部颗粒向炉底聚拢，合成为一个药渣结果物并飞到场景中央；
- 失败转化过程首版约1～1.5秒，具体速度通过配置调整；
- 药渣结果物支持悬停Tips，显示名称“药渣”、失败原因“药液流失过多”、本炉投入材料和最终药渣数量；
- 失败药渣数量等于失败瞬间未溶解药材、活动珠子和容器内容的剩余实体总体积除以一份药渣标准体积并向下取整；首版一份等于100个满体积标准珠的总体积；已烧毁、已落空和自然蒸发的内容不计入，只要仍有内容就至少产出一份；
- 失败药渣的全部数量合并在一个结果物上，Tips使用“药渣 × 数量”显示；当前材料使用统一换算规则，材料或丹炉专属倍率延后；
- 场景旁显示不遮挡药渣结果物及其Tips的“萃取失败”面板，面板只提供“再来一炉”按钮；
- 完成弹板只提供“再来一炉”按钮，不显示计时、药效保留率或精确珠子数量；
- “再来一炉”重置场景并恢复配置中的测试库存，当前原型不保存永久背包消耗；
- 炼制中途重新开始需要二次确认；
- 浏览器失去焦点或页面进入后台时自动暂停，物理、计时和药效流失同时停止。

“结束萃取”按钮、完成弹板和直接终止本轮的逻辑只用于当前独立萃取原型。未来实现融合阶段后，按钮替换为“进入融合”，完成弹板和原型终止逻辑删除；其他开始、暂停和重开规则继续保留。

## 6. 第四项：火候玩法

### 6.1 本项需要依次确定

1. 玩家如何控制火焰方向和大小；
2. 计算出的炉温是否向玩家显示具体数字；
3. 火焰大小与炉温如何关联；
4. 三个阶段分别如何记录火焰操作；
5. 保温如何操作和判定；
6. 温度变化如何影响标签反应；
7. 火候错误会产生哪些结果；
8. 火候通过哪些视觉和声音反馈给玩家。

### 6.2 已确认结论

#### 6.2.1 火焰控制与炉温变化

萃取阶段保留0～100火焰大小滑动条，并增加鼠标滚轮作为同一数值的快捷输入：

- 玩家通过鼠标移动控制火焰目标方向，火焰根部快速平滑追随，上层火流稍微滞后弯曲；
- 玩家按住鼠标左键喷火，松开左键立即关闭实际火流；
- 玩家通过鼠标滚轮或界面滑动条控制火焰大小，两个控件修改同一个0～100数值并双向同步；
- 火焰越大，覆盖范围越大，可以同时灼烧的掉落物越多，但也更容易误烧有效灵液；
- 火焰越小，覆盖范围越小、精准度越高，但难以处理密集药渣和杂质；
- 喷火开关、火焰方向和大小构成萃取阶段的主要火候操作；
- 炉温仍具有惯性，并继续通过竖向温度条显示。

火焰大小必须具有清晰的场景表现。大小变化至少可以影响：

- 火焰体积和高度；
- 火焰亮度和颜色变化；
- 火焰动态速度；
- 火星、烟气等粒子数量；
- 燃烧声音量和急促程度。

具体美术表现和参数映射在界面及表现设计阶段确定。

#### 6.2.2 火焰与炉温关系

玩家仍不直接设置炉温。系统内部使用0～100的标准化炉温，但不向玩家显示具体数字。界面设置的火焰大小在停火时继续保留，系统先计算有效火焰大小：

> 有效火焰大小 = 正在喷火 ? 已设置火焰大小 : 0

有效火焰大小与目标炉温采用以下配置化关系：

> 目标炉温 = 基础炉温 +（最高炉温 - 基础炉温）× 温度曲线（有效火焰大小 ÷ 100）

- 当前唯一火种使用线性温度曲线；
- 未按住鼠标左键或已设置火焰大小为0时，目标炉温等于基础炉温；
- 按住鼠标左键且已设置火焰大小为100时，目标炉温等于当前火种的最高炉温；
- 目标炉温高于实际炉温时，实际炉温按照可配置的升温速度逐渐接近目标；
- 目标炉温低于实际炉温时，实际炉温按照可配置的降温速度逐渐冷却；
- 基础炉温、最高炉温、温度曲线、升温速度和降温速度全部属于火种配置；
- 炉温不参与当前萃取中的药材溶解或药液自然流失计算；当前炉温只作为画面反馈和后续材料反应、融合、凝丹及丹炉特性可以读取的状态；
- 以后增加火种时，只替换火种配置，不修改萃取规则。

当前只保留以下原则：玩家直接控制空间中的火焰，系统计算实际炉温；材料反应读取实际炉温；玩家通过竖向温度条观察结果。

#### 6.2.3 炉温显示

丹炉温度不显示具体摄氏度数字。丹炉旁显示一条竖向温度进度条：

- 温度越高，进度条填充位置越高；
- 进度条颜色随温度由黄色逐渐过渡到红色；
- 玩家结合火焰大小、火焰场景表现和炉温进度条判断当前火候；
- 黄色到红色的具体渐变色值和视觉样式在界面设计阶段确定。

#### 6.2.4 火种特性

不同火种确定具有不同特性，但火种特性的字段、标签、强度和具体反应规则延后讨论，暂时不实现。

当前火种只需要影响：

- 火焰与丹炉温度之间的关系；
- 升温和降温表现；
- 火焰的视觉及声音表现。

火种参与材料反应、隐藏反应和异变的机制作为后续扩展保留。未来火种还可以拥有快速灼烧药渣精灵珠和杂质精灵珠、保护特定药液精灵珠、追踪指定目标等萃取技能。

#### 6.2.5 火候操作记录与重放

系统自动记录玩家在萃取、融合和凝丹三个阶段中的完整火候操作，玩家不需要手工填写数据。

记录内容包括：

- 鼠标左键控制的喷火开启与关闭轨迹；
- 火焰方向的变化轨迹；
- 火焰大小数值的变化轨迹；
- 火焰在不同方向和大小下的持续时间；
- 接液容器通过 `A`、`D` 移动的轨迹；
- 实际烧毁、漏接和接入容器的灵液、药渣与杂质；
- 萃取进入融合、融合进入凝丹的切换时机；
- 三个阶段中的温度变化；
- 本炉总用时、三个阶段各自的用时以及最终药效保留率。

丹方可以将三个阶段分别显示为简化的喷火开关、火焰大小、温度和操作轨迹。使用丹方快速炼制时，系统自动按照原记录重放喷火开关、火焰方向、大小变化、接液容器移动和阶段切换。

火候操作记录的是一炉炼制中的短时间实际操作。操作期间会持续发生非常缓慢的药效流失，但不引入要求玩家长时间等待的炼制时长系统。

#### 6.2.6 保温操作

系统不设置独立的“保温”按钮。保温是玩家通过火焰操作，使丹炉温度在一段时间内保持相对稳定后形成的实际状态。

- 玩家通过竖向炉温进度条判断温度是否稳定；
- 保温可以发生在萃取、融合或凝丹任意阶段；
- 成丹配置可以要求某个阶段处于特定温度范围并维持稳定；
- 研制丹方时不直接显示正确保温答案，玩家根据过程反馈自行探索；
- 系统把保温过程作为火候操作的一部分自动记录并在快速炼制时重放。

#### 6.2.7 反应读取实际炉温

材料反应和成丹条件读取系统计算出的实际丹炉温度，不直接把鼠标方向或火焰大小当作温度。

- 火焰操作是玩家影响炉温和直接灼烧对象的输入；
- 不同火种在相同火焰大小下可以产生不同炉温和反应结果；
- 反应规则可以匹配当前炼制阶段、炉温范围、升温或降温趋势，以及保温持续状态；
- 玩家通过竖向温度进度条和炉内反馈判断实际炉温，不需要查看具体温度数字。

#### 6.2.8 火候错误的结果

系统不设置统一的“火候错误扣成功率”，也不使用隐藏的炼丹成功率决定温度偏差是否失败。实际炉温通过具体标签反应和成丹配置产生后果。

- 温度过低时，材料标签可能未被激活或萃取不足；
- 温度过高时，功效可能流失、材料可能损毁或产生风险标签；
- 火焰直接接触灵液、药渣或杂质时，可以把对应对象灼烧掉；
- 火焰大小或方向控制不当时，可能误烧灵液或漏掉药渣与杂质；
- 升温过快时，可能触发易燃、挥发、爆裂等反应；
- 温度波动过大时，可能导致融合不完整、残丹或副作用；
- 凝丹温度不合适时，可能形成残丹、废丹或药渣；
- 只有极端危险反应满足配置条件时才会炸炉。

温度偏差不直接触发无原因的随机失败。每一种结果都应能从材料标签、实际炉温、阶段和反应过程得到解释。

#### 6.2.9 火候反馈

系统反馈当前炼制现象，但不直接提示“火候正确”“火候错误”或应该如何操作。

火候反馈包括：

- 火焰大小、颜色和稳定程度；
- 黄色到红色的竖向炉温进度条；
- 药液颜色、黏稠度、气泡、结晶和翻滚程度；
- 药液精灵珠、药渣精灵珠和杂质精灵珠的颜色、轮廓、移动和互动表现；
- 药液精灵珠被灼烧、漏接或成功进入容器的即时效果；
- 少量药液向上飘到丹炉壁并化为蒸汽的缓慢药效流失表现；
- 丹炉发红、震动、裂纹和烟气；
- 平稳燃烧、沸腾、闷响和尖锐异响等声音；
- 丹炉旁短暂显示“传来清香”“出现焦糊味”等气味文字；
- 极端危险时使用红色闪烁、剧烈震动和警示音。

玩家根据现象自行调整火焰方向与大小并总结丹方，系统不弹出正确答案。

#### 6.2.10 第四项完成状态

鼠标左键控制喷火开关、鼠标控制目标方向、滚轮与滑动条共同控制火焰大小、配置化炉温计算、温度显示、温度惯性、保温、操作轨迹记录、直接灼烧、反应触发、错误后果和现象反馈已经确定。

火种自身的特殊标签和反应规则作为后续扩展保留，不阻塞当前流程。

## 7. 第五项：丹炉规则

### 7.1 本项需要依次确定

1. 丹炉基础差异是否需要实现；
2. 炉内残留是否在当前实现；
3. 炉内残留如何产生、保存和消耗；
4. 玩家能否查看、清理或利用炉内残留。

### 7.2 已确认结论

#### 7.2.1 丹炉暂不设计差异

当前所有丹炉使用同一套基础行为，暂时不设计不同丹炉之间的差异。

- 丹炉不影响火种与火焰操作计算出的炉温；
- 当前炉温不影响药材溶解或药液自然流失；未来可以把温度影响流失设计成不同丹炉的特点；
- 不设置丹炉特性标签；
- 不设置丹炉品质、耐久或损坏；
- 不设置丹炉装料容量或单炉产量上限；
- 不需要围绕属性差异选择或更换丹炉。

不同炉型、特殊标签、反应亲和和其他丹炉差异统一作为后续扩展保留。

此前提出的炉内残留属于单个丹炉经过炼制后形成的动态状态，不归入炉型差异，是否在当前实现继续单独确认。

#### 7.2.2 炉内残留延后

炉内残留当前不实现。暂不设计残留标签、残留强度、查看、清理、消耗和跨炉次影响。

炉内残留继续保留在总体设计中，未来可以作为隐藏反应和惊喜机制的扩展来源。

#### 7.2.3 第五项完成状态

当前丹炉不设计任何炉型差异或动态残留，只作为场景中的统一炼制容器。第五项“丹炉规则”完成，所有差异化能力延后。

## 10. 第八项：惊喜机制

## 11. 第九项：丹方机制

### 11.1 本项需要依次确定

1. 同一种丹药通过不同过程炼成时如何保存丹方；
2. 丹方界面如何展示材料、投药、火焰轨迹和接液过程；
3. 快速炼制前需要玩家准备哪些条件；
4. 快速炼制如何重放投药、阶段、火焰操作和接液过程；
5. 快速炼制结果允许哪些轻微变化；
6. 快速炼制生成异变时如何处理；
7. 玩家能否删除、改名或整理丹方。

### 11.2 已确认结论

#### 11.2.1 丹方生成与唯一性

成丹后自动生成丹方，未成丹、药渣和炸炉不生成丹方。

当前以“丹药配置 + 品阶”确定唯一丹方：

- 同一种丹药的下品、中品、上品和极品分别形成不同丹方；
- 同一种丹药且品阶相同时，只保存第一次成功炼制形成的丹方；
- 后续用不同过程炼出相同丹药和品阶时，不新增重复丹方，也不自动覆盖首次丹方；
- 丹纹机制暂不实现，不参与丹方命名或唯一性判定；
- 多种炼制方案、丹方优化和覆盖功能以后再扩展。

#### 11.2.2 丹方界面展示

丹方使用列表面板管理。玩家选中一份丹方后，详情区域显示：

- 丹方名称和目标丹药品阶；
- 目标丹药的主功效、次要功效、副作用和特殊特质；
- 所需材料、数量及材料状态；
- 材料投入顺序；
- 每份材料在萃取阶段中的投入时机；
- 使用的火种；
- 萃取、融合、凝丹三个阶段的火焰方向、大小、温度和操作轨迹；
- 接液容器的移动轨迹和实际收集结果；
- 阶段切换时机；
- “快速炼制”按钮。

当前丹方界面不显示丹炉差异、环境、天时、丹纹和炉内残留，因为这些机制均已延后。

#### 11.2.3 快速炼制的材料与倍数

快速炼制使用丹方首次形成时记录的具体材料、材料状态和火种，不自动使用具有相同标签的其他材料替代。

- 丹方记录首次成功时的材料数量和基础产量；
- 玩家选择本次炼制1倍、2倍、3倍等整数倍数；
- 所需材料数量按照倍数增加，预计成丹数量根据丹方可复现的收集结果同比计算；
- 系统自动从背包匹配原丹方使用的具体材料；
- 材料的保存状态、生长来源和年份必须与丹方记录一致；
- 玩家必须拥有丹方记录的火种；
- 材料或火种不足时，界面显示缺少的内容并禁止开始；
- 玩家确认后一次性扣除所需材料，随后开始重放丹方流程。

#### 11.2.4 快速炼制过程重放

快速炼制不瞬间生成结果，而是在场景中使用加速动画自动重放丹方流程。

- 系统自动按照丹方记录投入材料；
- 自动重放萃取、融合、凝丹三个阶段、火焰方向变化、大小变化和接液容器移动；
- 萃取掉落物使用丹方记录的生成序列或可复现随机种子，确保自动重放时原操作轨迹能够得到对应收集结果；
- 火焰、竖向炉温、药液和炉声继续显示对应表现；
- 整套过程加速到几秒内完成；
- 加速只压缩动画播放时间；最终药效仍按照丹方记录的原始阶段用时和药效保留率计算，避免快速炼制凭空提高药效；
- 快速炼制期间玩家不能改变火焰、接液容器、投药或阶段，也不能暂停或接管；
- 完成后丹药或药渣照常从丹炉飞出并显示 Tips。

具体加速倍率和动画时长以后通过配置调整。

#### 11.2.5 快速炼制的轻微随机

快速炼制只随机主功效、次要功效和副作用内部已经配置的具体参数。每个参数单独配置最小值和最大值，不使用统一的全局浮动百分比。

- 主功效、次要功效和副作用的类型不变；
- 特殊特质不变；
- 丹药品阶不变；
- 成丹数量不因随机额外减少；
- 没有配置随机范围的参数保持固定；
- 配置了范围的参数在对应最小值与最大值之间独立取值。

例如丹方可以配置“恢复生命95～105点”“持续28～32秒”“虚弱8～12秒”，每次快速炼制在各自范围内产生结果。

#### 11.2.6 快速炼制暂不触发异变

当前基本版本的快速炼制不触发异变，也不在丹药名称后增加“异变”二字。

- 快速炼制只产生已经确定的功效参数小幅随机；
- 丹药基础名称、功效类型、特殊特质和品阶保持不变；
- 丹方名称保持不变；
- 异变机制继续作为后续扩展保留；
- 以后实现异变时，快速炼制需要先满足材料、环境、天时等因果条件，原丹方名称仍然不增加“异变”。

#### 11.2.7 丹方管理

当前丹方管理保持简单：

- 丹方使用系统名称，玩家不能改名；
- 玩家可以删除丹方，删除前需要进行确认；
- 删除丹方只移除丹方记录，不影响已有丹药、材料或其他数据；
- 删除后再次炼出相同丹药和品阶时，系统重新自动生成丹方；
- 当前不提供文件夹、收藏、标签和手动排序；
- 丹方列表默认按照丹药配置顺序和品阶排列；
- 玩家修改具体丹药物品名称时，不影响丹方名称。

#### 11.2.8 第九项完成状态

丹方自动生成、唯一性、界面信息、快速炼制材料检查、批量倍数、过程重放、参数随机、异变边界和删除功能均已确定。第九项“丹方机制”完成。

#### 13.2.2 萃取玩法属于第一阶段核心范围

第一阶段必须实现本轮新增的萃取操作闭环：

- 从背包选择一种或多种药材并放入上方萃取区域；
- 背包左键预选、悬浮药材左键投入和右键取消能够正确增减待投数量与背包数量；
- 药材以纯平面多边形素材按配置化显式槽位自动排布，相同材料的多份投入各占一个互不重叠的槽位；
- 槽位按投药顺序确定；药材溶解时保持原位置，不发生坍塌或重新排列；
- 火焰固定从药材摆放区下方向上灼烧，并被未溶解药材和三类精灵珠阻挡；火流像水流绕柱一样分向实体两侧继续向上，不会穿过实体本身；
- 火源暂时固定在丹炉内部中间、接液容器轨道上方，只允许在朝上的可配置扇形范围内转向；
- 火源上方为灼烧区，珠子越过火源向下后进入安全接取区，不再挡火、受火焰伤害或火焰推力；
- 火流能够推动三类精灵珠，界面提供默认开启的临时“火焰推力”开关供试玩时即时对比；
- 药材从实际受热位置按照隐藏成分分布图逐步转化为药液精灵珠、药渣精灵珠和杂质精灵珠；
- 每份标准药材生成约300颗精灵珠，基准数量为药液约75颗、药渣约180颗、杂质约45颗；
- 同一种药材的主体分布固定，仅对分布边缘、珠子生成位置和初始速度做轻微随机；
- 鼠标控制火焰目标方向，火焰使用可配置的平滑转向和上层滞后；
- 按住鼠标左键喷火，松开立即关闭实际火流；
- 鼠标滚轮和界面滑动条共同控制同一个0～100火焰大小数值，并保持双向同步；
- 丹炉温度使用黄色到红色的竖向进度条表现，但炉温不改变当前萃取中的药材溶解速度；
- 火焰可以烧毁三类精灵珠；
- 三类精灵珠首次接触火焰时具有可配置的保护时间、护盾与声音反馈，并支持配置离火后是否重置保护；
- 药液精灵珠持续受伤时逐渐缩小并最终消失；
- 部分灼烧后的三类精灵珠按照剩余体积向容器贡献有效量或污染量；
- `A`、`D` 控制底部接液容器左右移动；
- 接取成功的精灵珠保留形态和剩余体积停留在容器中；
- 不同药材生成的药液精灵珠使用可辨识的视觉表现；
- 三类精灵珠使用不同的轮廓、纹理、运动和受伤表现，并对大量同时触发的叫声进行配置化合并；
- 精灵珠按照可配置的初速度、重力、最大速度、漂移和墙壁反弹规则运动；
- 三类精灵珠与尚未溶解的药材实体碰撞，可以反弹、滑落或暂时停留；药材溶解形成的缺口同步允许珠子通过；
- 药液精灵珠在灼烧区和安全接取区都可以触发一个配置化争斗案例，用于验证邻近查询、触发、动画、声音和轨迹改变；
- 投入第一份药材后开始萃取计时并缓慢流失药效，萃取没有固定总时限；流失只通过药液向上飘到丹炉壁并化为蒸汽表现；
- 药液自然流失使用固定的每分钟约1%作为首版参考值，当前不受炉温影响；
- 药液珠被实际烧掉的体积立即计入流失，落空时按照剩余体积继续计入流失，接住后剩余药液不再流失；药渣和杂质只累计污染；
- 落空时仍有剩余体积的珠子进入炉底药渣池；已经烧掉的体积不计入，只触发护盾但未缩小的珠子按100%计入，完全烧毁的珠子不进入；当前萃取原型记录其类型和剩余体积，未来成功成丹时统一产出药渣；
- 流失达到50%和65%时分别触发不显示数字的两级视觉警告；超过70%时本轮立即失败并停止全部操作；
- 失败时所有未溶解药材、场上精灵珠和容器内容经过约1～1.5秒的焦黑、碎裂和聚拢表现，合成为一个飞出丹炉的药渣结果物；
- 药渣结果物具有Tips，失败面板不遮挡结果物及其Tips，并只提供“再来一炉”按钮；
- 所有药材完全溶解，并且所有在场精灵珠被接住、烧毁或落空后，临时“结束萃取”按钮变为可用；
- 玩家点击后停止模拟并显示临时完成弹板，精灵珠继续停留在容器中，本轮原型流程结束，不进入融合；
- “结束萃取”按钮和完成弹板在未来接入融合流程后删除。

不同火种技能、不同接液容器、丹炉差异、融合、凝丹、成丹结果、品阶、丹方和快速炼制继续延后。

#### 13.2.3 萃取原型验收标准

1. 玩家能够通过背包左键预选、悬浮药材左键投入和右键取消，正确管理并投入一种或多种配置材料；
2. 玩家能够通过鼠标左键、受朝上扇形限制的鼠标目标方向、滚轮、滑动条和 `A`、`D` 完成全部核心操作；固定火源位置可通过配置调整；
3. 药材能够按照配置的成分分布图和火流可到达区域局部溶解；小范围火流集中打孔、大范围火流广泛剥离，并从实际溶解位置生成三类可辨识的精灵珠；正面火与绕流后的火使用相同灼烧强度；
4. 低分辨率二维流场能够把药材剩余形状作为完全障碍，并按照覆盖面积把单颗珠子写为部分障碍、多颗珠子叠加为更强障碍；火焰被正确阻挡后像水流绕柱一样沿实体两侧继续向上，画面火流与实际灼烧及推力区域一致，且火焰不会穿过实体；
5. 三类精灵珠不能穿过尚未溶解的药材，可以在药材上反弹、滑落或停留，并在对应位置溶解后通过形成的缺口；珠子越过火源向下后正确进入不再挡火、受伤或受推力的安全接取区，但仍能继续触发配置化互动；
6. 精灵珠的护盾、声音、持续灼烧缩小、离火重置、剩余体积和火焰推力能够正确工作；临时推力开关可以即时启停新的推力且不清除已有速度；
7. 接住、烧毁和落空三种结算路径都能正确累计有效量、流失量或污染量；部分灼烧后落空的珠子能够按照剩余体积进入炉底药渣池，已烧掉体积和完全烧毁珠子不会产生药渣；药渣池能够按统一标准体积换算正常成丹药渣数量；
8. 药效流失能够以全部已投入材料的理论药液总体积为分母，正确累计暴露药液的固定自然流失、被实际烧掉的药液体积和落空药液珠的剩余体积，且不受当前炉温影响；接住的药液珠停止自然流失，药渣和杂质不计入流失；追加材料前后流失率保持不变；
9. 药效流失具有缓慢的蒸汽视觉表现，但界面不显示计时或保留率；流失达到50%和65%时能够正确触发两级非数字视觉警告；
10. 流失超过70%时能够立即停火、停止计时并禁用操作；所有未溶解药材、场上精灵珠和容器内容能够经过可配置的转化动画，稳定合成为一个药渣结果物；
11. 失败药渣数量能够按照失败瞬间的剩余实体体积和药渣标准体积正确换算，且最低数量规则有效；结果物能够从丹炉飞到场景中央并显示完整Tips；“萃取失败”面板不遮挡结果物或Tips，且只提供“再来一炉”按钮；
12. 所有药材和精灵珠完成结算后，“结束萃取”按钮能够正确启用；点击后系统稳定停止模拟并显示临时完成弹板；
13. 材料外观图、64×64成分分布图、标准精灵珠体积、基础溶解速度、药液流失速度与警告阈值、失败转化时间、精灵珠保护时间、灼烧时间、移动速度和容器参数均通过配置调整并经过加载校验；
14. 不依赖融合、凝丹或丹方系统，也能反复开始并完成一轮萃取。

#### 13.2.4 配置文件结构

萃取原型使用独立配置目录，当前结构为：

```text
config/
├─ prototype.json
├─ parameters.json
├─ materials/
├─ fire-sources.json
├─ pearl-types.json
├─ collector.json
└─ interactions.json
```

- `prototype.json`：场景、测试库存、临时原型流程和试玩开关的初始状态；
- `parameters.json`：暂时不值得拆成独立文件的零散参数表；
- `materials/`：8种药材分别配置稳定ID、正常中文显示名、五类标签、透明多边形外观PNG、64×64成分PNG、目标珠子数量和必要覆盖项；
- `fire-sources.json`：火种、目标炉温曲线、升降温速度、火流注入和基础推力参数；
- `pearl-types.json`：三类精灵珠的通用运动、护盾、灼烧、受力倍率、表现和声音规则；
- `collector.json`：接液容器移动与接取参数；
- `interactions.json`：争斗等邻近互动规则。

`parameters.json`中的参数按照场景、界面、时间、随机和调试等主题分组，并为每项定义稳定键名、数值类型、单位、默认值和合法范围。时间分组包含标准有效火流持续灼烧约120秒的标准材料溶解基准、固定自然流失速度、50%与65%警告阈值，以及70%失败阈值；数量分组包含一份药渣标准体积，以及失败和正常成丹药渣的最低数量，一份药渣标准体积首版默认等于100个满体积标准精灵珠。药液珠被实际烧掉的体积和落空时的剩余体积分别计入流失；所有落空珠子只把尚存体积计入炉底药渣池。二维流场的网格分辨率、更新频率、绕流、汇合和障碍覆盖换算等模拟级参数放在参数表的模拟分组；当前不配置火流强度衰减；已有明确归属的火种注入与统一基础推力参数仍放在对应专用配置中，不重复写入参数表。

配置统一遵循以下规则：

- 程序通过稳定ID关联数据，不使用中文显示名作为引用；
- 时间统一使用秒，速度统一使用场景单位每秒，比例使用0～1，标签强度使用0～100；
- 每份配置包含`schemaVersion`；
- 公共默认值只定义一次，具体材料只覆盖差异；
- 启动时统一校验缺失字段、非法ID、数值范围、资源路径和成分图颜色；
- 配置错误时在开发界面显示明确的中文错误，不静默采用错误数据；
- 配置只选择争斗、排斥、融合等受支持的通用行为类型，不允许写入任意脚本。

#### 13.2.5 网页技术方案与代码边界

当前萃取原型采用：

- **Vite + TypeScript**：工程、开发服务器和生产构建；
- **Phaser 4.1.x**：2D场景、精灵渲染、输入、声音和资源生命周期；
- **原生HTML/CSS**：背包、滑动条、按钮和临时完成弹板，不引入React；
- **Vitest**：配置校验、炉温、溶解、精灵珠状态、接取和完成判定等规则测试。

Vite只负责转译TypeScript，项目检查额外运行`tsc --noEmit`。依赖版本通过锁文件固定，不在未经验证时自动跨大版本升级。

代码目录按以下边界组织：

```text
src/
├─ domain/       与Phaser无关的萃取规则
├─ simulation/   二维火流、精灵珠运动、对象池和空间网格
├─ game/         Phaser场景和画面表现
├─ ui/           HTML/CSS界面
├─ config/       配置加载与校验
└─ tests/        规则测试
```

- `domain/`和`simulation/`不能引用Phaser，保证规则可独立测试，并为以后迁移Unity保留清晰边界；
- Phaser层只负责输入、渲染、音效、资源和把规则状态表现到场景；
- 低分辨率二维火流在`simulation/`中固定步长更新，默认30次/秒；药材剩余形状和精灵珠作为动态障碍写入流场，渲染层以60帧插值显示；
- 药材溶解、精灵珠灼烧、火焰推力和火焰画面统一采样该流场，不能分别维护互相矛盾的判定；
- 64×64成分图由规则层采样，表现层使用平滑动态遮罩显示局部溶解；
- 数百至数千颗精灵珠使用轻量Sprite、对象池和自定义运动，不为每颗珠子创建完整刚体；
- 邻近互动使用空间网格；
- 占位图形预先生成纹理，不在每帧重绘大量复杂图形；
- 不实现自动画质降级，也不因性能自动删除真实精灵珠或减少已经确认的粒子、余焰、烟气、声音及其他特效；
- 当前不需要后端服务，配置与素材全部作为本地静态资源加载。

技术依据参考：[Vite官方文档](https://vite.dev/guide/)、[Vite TypeScript说明](https://vite.dev/guide/features)、[Phaser 4.1 API](https://docs.phaser.io/api-documentation/api-documentation)、[Phaser官方文档](https://docs.phaser.io/)、[Vitest官方文档](https://vitest.dev/guide/learn/writing-tests)。

#### 13.2.6 网页场景尺寸、布局与输入边界

当前原型只面向桌面端鼠标与键盘操作，不适配触屏操作。场景采用1600×900的16:9逻辑分辨率，在浏览器窗口内等比缩放并居中显示。开发和验收时至少检查1920×1080与1366×768两种显示尺寸，确保核心操作区和界面均不被裁切。

默认布局如下：

- 丹炉放置在画面中央，作为主要玩法区域；
- 已选择但尚未投入的药材悬浮在丹炉左右两侧；
- 已投入药材以纯平面多边形素材自动分配到互不重叠的配置化槽位，位于丹炉上方；
- 火源固定在丹炉内部中间、接液容器轨道上方，并显示明确的喷火起点；
- 接液容器位于丹炉内部下方，并沿水平轨道移动；
- 背包固定在屏幕底部，默认约占逻辑画面高度的22%；
- 竖向炉温条、火焰大小滑动条和临时“火焰推力”开关放置在丹炉右侧；
- 临时“结束萃取”、暂停和重新开始按钮放置在右上角；
- 场景对象与界面区域的位置、尺寸、间距和边距全部从配置读取。

输入边界如下：

- 鼠标位于游戏场景的非交互空白区域时，鼠标移动控制火焰目标方向，滚轮控制火焰大小，从该区域按住左键时喷火；
- 左键点击背包药材时预选一份，左键点击悬浮待投药材时投入一份，右键点击悬浮待投药材时取消一份，均不会点火；
- 炼丹操作区禁用浏览器默认右键菜单；
- 鼠标位于背包、滑动条、按钮或弹板等HTML界面区域时，界面操作优先，在界面上按下左键不会点火；滑动条、按钮和弹板区域中的鼠标移动与滚轮不改变火焰；
- 左键在窗口内任意位置松开时都立即停火；
- 操作滑动条时，滑动条继续与火焰大小数值双向同步；
- 弹板打开、浏览器失去焦点或页面进入后台时，强制停火并自动暂停物理、计时和药效流失；恢复后不会自动重新喷火；
- 暂停后不积累补帧时间，恢复时从暂停状态继续。

#### 13.2.7 性能目标与表现保护

性能验收先以当前开发电脑上的桌面版Chrome或Edge为准：

- 正常测试场景同时存在约900颗活动精灵珠，目标保持60帧画面和每秒30次流场更新；
- 压力测试场景同时存在约2400颗活动精灵珠，目标画面不低于45帧，流场仍保持每秒30次更新；
- 实际玩法通常不会同时出现压力测试数量，该场景只用于验证性能余量；
- 不设置精灵珠数量的玩法硬上限，不因性能自动删除、合并、跳过或简化真实精灵珠规则；
- 已接取珠子切换为只保留必要表现的轻量展示对象；
- 精灵珠对象池按照配置预热并允许扩展；
- 开发模式提供默认隐藏的调试面板，显示帧率、活动珠子数量、流场耗时和互动数量；
- 系统不实现自动画质降级，不能自动减少粒子、余焰、烟气、声音或其他已经确认的特效；
- 性能不达标时，优先优化流场、对象池、空间查询、数据布局和绘制批次；任何删减特效或降低表现质量的方案都必须先获得确认。

#### 13.2.9 药材素材技术规范

首版与后续正式药材统一遵循以下资源规范：

- 外观图为512×512 RGBA PNG，透明背景，单份药材采用俯视纯平面构图；
- 药材主体居中，四周保留少量透明边距；
- 素材不烘焙阴影，程序也不生成药材投影；多份药材依靠独立槽位、间距和轮廓辨识；
- 场景中的默认显示长边约为180逻辑像素，单种材料可以通过配置覆盖；
- 成分图严格为64×64 RGBA PNG，与外观图使用完全相同的归一化坐标；
- 成分图不使用抗锯齿、渐变或有损压缩，只允许透明空白、青色药液、灰色药渣和紫色杂质四种精确值；
- 当前精确色建议固定为药液`#00FFFF`、药渣`#808080`、杂质`#800080`，空白像素Alpha为0；
- 外观图使用平滑采样，成分图使用最近邻采样；
- 成分图非空区域必须位于外观图药材轮廓内部，越界时加载器显示中文配置错误并拒绝开始；
- 旋转、缩放和溶解遮罩由程序处理，不为不同角度重复制作素材；
- 外观图、成分图和后续正式美术产物均保留PNG格式。

#### 13.2.10 首版视觉方向

当前网页原型采用“中国志怪炼丹图鉴”的手绘平面风格：

- 药材使用俯视剪纸感、清晰深色描边和少量内部纹理，不使用阴影；
- 多份药材依靠轮廓、独立槽位、间距和颜色区分；
- 丹炉内部以暗青铜、暗红和深褐为主，衬托火焰与精灵珠；
- 火焰使用明亮的黄、橙、红渐变，绕流、分叉、遮蔽和汇合必须清晰可见；
- 药液珠保留可爱精灵表情，药渣使用粗糙破碎的视觉语言，杂质使用尖刺阴森的视觉语言；
- 背包、Tips和按钮使用简洁的旧纸与铜边风格，不堆叠过量装饰；
- 五类标签和0～100渐变进度条以清晰可读为优先；
- 参考画面只借鉴平面物品规则排布的可读性，不复制其具体界面布局或美术；
- 视觉主题属于可替换表现层，主题颜色、描边、界面纹理和字号通过集中样式或主题配置维护，不进入萃取规则。

#### 13.2.11 首版萃取节奏与失败阈值

首版先使用以下节奏基准，所有数值均通过`parameters.json`配置，并根据试玩感受调整：

- 一份标准药材受到标准有效火流持续直接灼烧时，约需120秒完全溶解；
- 炉温不参与药材溶解计算；当前火流不区分正面、侧面或绕流后的强弱，只判断能否到达，没有实际火流接触时完全停止溶解；
- 萃取没有固定总时限，玩家没有持续灼烧时进行6～7分钟属于正常操作；
- 投入第一份药材时开始萃取内部计时；尚未投药时的试火和升温不计时，暂停或浏览器进入后台时计时停止；
- 自然流失首版使用固定的每分钟约1%作为参考值，不受炉温影响；温度影响流失的方案保留为未来不同丹炉的特点；
- 药液珠被实际烧掉的体积立即计入本炉药液流失，落空时按照剩余体积继续计入流失；已经接入容器的剩余药液不再流失；
- 药渣和杂质不计入药液流失，只累计污染并影响后续品质；
- 药液流失率以全部已投入材料的理论药液总体积为分母，以累计自然蒸发、烧掉和落空的药液体积为分子，并限制在0%～100%；
- 自然流失只作用于未溶解药材中尚存的药液和场上活动药液珠，不作用于已经接入容器的药液；
- 中途追加药材仍然允许；新增理论药液量按本炉当前流失率同步增加对应流失量，使追加前后的流失率保持不变，不能通过投药降低或恢复已经累计的流失；
- 药液流失达到50%时，蒸汽明显增多且药液颜色开始变淡；达到65%时，蒸发明显加剧，场上药液精灵珠表现出慌张或虚弱；
- 两级警告不显示精确数字，阈值和表现强度支持配置；
- 当本炉药液累计流失超过70%时，本轮萃取立即失败并停火；所有未溶解药材、场上精灵珠和容器内容全部转化为药渣；
- 失败内容经过约1～1.5秒的焦黑、碎裂和聚拢动画，合成为一个飞到场景中央的药渣结果物；结果物Tips显示失败原因、投入材料和数量；
- 失败药渣数量按照失败瞬间尚存的未溶解药材、活动珠子和容器内容的剩余实体总体积换算；已烧毁、已落空和自然蒸发的内容不计入，总量向下取整且最低为一份；
- “萃取失败”面板不遮挡药渣结果物及其Tips，只提供“再来一炉”按钮；
- 界面仍不显示计时数字、倒计时进度条或预计完成时间；
- “添药救炉”作为后续扩展建议保留；当前版本追加药材不会改变本炉现有流失比例。
- 正常成功成丹时，落空但尚有剩余体积的珠子按剩余体积进入炉底药渣池；已烧掉的体积不产生药渣，完全烧毁的珠子不进入药渣池。
- 正常成功时，炉底药渣池总体积除以统一药渣标准体积并向下取整；首版标准体积等于100个满体积标准珠；药渣池为空时不产出，只要有内容就最低产出一份；三类来源合并为一个显示“药渣 × 数量”的结果物并与丹药分别飞出。

#### 13.2.12 萃取闭环开发就绪结论

当前独立萃取原型已经具备可实施的完整边界：材料与成分资源、投药与不重叠槽位排布、二维绕火、局部溶解、三类精灵珠、灼烧保护与伤害、火焰推力、接液容器、珠子互动、药液流失、失败转化、炉底药渣池、临时结束流程、配置结构、代码边界、性能目标和验收标准均已确定。

环境、天时、丹炉差异、火种特殊能力、融合、凝丹、正式成丹、丹纹、炉内残留、开放、密闭、泄压和手动分离均明确延后，不阻塞当前网页端萃取原型开发。后续试玩只调整配置参数和表现手感，不需要先补充新的核心规则。
