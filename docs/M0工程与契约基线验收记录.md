# M0 工程与契约基线验收记录

记录日期：2026-07-14

## 1. 本轮边界

M0 只建立可重复安装、可检查、可生产构建的网页工程，以及后续玩法实现必须依赖的配置、确定性和应用契约。正式 8 种材料、512×512 外观图、完整标签体系、火流求解与性能场景仍按实施计划分别留在 M1/M4，不用假数据冒充已完成玩法。

当前运行配置只登记 1 份最小合成材料和 1 张真实 64×64 RGBA 成分 PNG，用于证明加载、拒绝启动、素材校验和指纹链路。

## 3. 已冻结的技术契约

### 3.1 配置与素材

- 原始配置唯一契约为 JSON Schema，网页与 Node 校验入口复用同一组 Ajv 规则。
- JSON 文本在进入 Ajv 前使用共用严格解析边界；顶层、嵌套与转义等价重复键以 `CONFIG_DUPLICATE_JSON_KEY` 拒绝，不接受 `JSON.parse` 的静默 last-write。
- `standardPearlVolume` 默认 `1`，仅 parameters 可定义；`slagUnitVolume` 默认前者的 `100` 倍，仍仅 parameters 可定义。
- `targetPearlCount` 默认 `300`，仅 material 可覆盖，范围为整数 `1..100000`。
- 标准化结果递归冻结；网络、非 JSON、Schema、引用、范围、所有权和 PNG 问题都返回稳定错误码、文件路径、字段路径与中文说明。
- 配置或成分图不合法时不创建 Phaser Canvas，页面进入 `config-error`。

### 3.2 `simulationContentFingerprint` v1

- canonical JSON 使用 RFC 8785/JCS 语义，拒绝非有限数和孤立 surrogate。
- framing 固定为 `LDFP` magic、版本 `1`、无符号大端 `u32` 长度和记录数。
- 规则记录按逻辑键与记录类型的 UTF-8 字节序排列；文件路径不进入 payload。
- 成分图 payload 固定写入大端 width/height，再写入解码后的 16384 个 RGBA 字节。
- 浏览器禁用 PNG 色彩空间转换与 alpha 预乘；完全透明像素的隐藏 RGB 在 Node/浏览器统一归零，半透明像素拒绝，从而消除 `gAMA` 与解码器差异。
- 最终摘要为 SHA-256 小写十六进制。

跨语言 golden 位于 `test-vectors/fingerprint/v1-golden.json`，摘要为：

```text
d3a0b6c9adbe1cedd2455611c19c09d926e6d12be72e42b16b6b6c6e50ae80bc
```

当前公开最小配置与素材的运行指纹为：

```text
af8a8fb4bc21a051d34fc4fc025bf0791d65bac65fa82bee2b78ca97a9e72aec
```

测试已锁定键序、路径重命名和 PNG 等价重编码不变；规则值、稳定 ID、数组顺序和解码 RGBA 改变必变。

### 3.3 确定性随机源

- 算法版本为 `xorshift32-v1`，所有状态转换按 uint32 溢出。
- 根 seed 为零时使用固定非零替代值。
- rules 与 visual 通过固定 salt 派生为独立流；额外消费 1000 次视觉随机不会改变规则流。
- 跨语言数值向量位于 `test-vectors/rng/xorshift32-v1.json`。

### 3.4 应用、领域与模拟边界

- 浏览器入口统一分配 session 内连续 sequence；规则与控制共享序列。
- `beforePhase0(deliveryBoundaryTick)` 先整批记录与 sequence 预检，再按总 sequence 逐条处理。
- 非负安全整数 `targetTick`、所有有限规则命令和应用控制均有运行时 payload 校验。
- control pump 非重入，并与 phase 0～10 互斥；暂停时不推进规则 tick。
- 成功 reset 建立 cutover，归档旧 session，丢弃旧队列与同批后续输入，新 session 从 tick 0 / sequence 1 开始。
- 命令许可矩阵、ready/extracting/failed/completed 状态、`PearlEntity`、`SimulationDelta`、newborn 下一 tick 和 `burned > caught > missed` 已冻结。
- `SimulationDelta` 候选在临时副本校验累计 dissolved/born 余额、非负、终态/newborn eligible 后才提交；失败返回原状态同一引用。
- application/domain/simulation 有自动边界测试，禁止引用 Phaser、DOM、资源 URL、墙钟或 `Math.random()`。

三组 reset cutover 与确定性元数据保存在 `test-vectors/application/reset-cutover.json`。

## 4. 验证结果

| 命令 | 结果 |
| --- | --- |
| `npm ci --registry=https://registry.npmjs.org/` | 从锁文件干净安装 82 个包；0 个漏洞 |
| `npm run typecheck` | 通过 |
| `npm run test` | 11 个文件、146 项测试全部通过 |
| `npm run test:coverage` | 146 项通过；总行覆盖率 89.24%，分支覆盖率 78.44% |
| `npm run validate:config` | 1 份材料通过；默认值为 1 / 100 / 300 |
| `npm run validate:assets` | 1 张 64×64 成分图通过；输出运行指纹 |
| `npm run build` | production build 通过 |
| `npm run check` | 类型、测试、配置、素材和构建全链通过 |
| `npm run test:e2e` | Chrome / Edge 共 12 项通过 |

浏览器 E2E 覆盖：

- Chrome 与 Edge 的 1920×1080、1366×768；
- 1600×900 Canvas 等比缩放、居中且不裁切；
- `parameters.json` 越界时显示稳定错误码与中文原因，不创建 Canvas。
- `gAMA` 与完全透明隐藏 RGB 不改变 Node/浏览器规范 RGBA 指纹；半透明成分像素稳定拒绝。
- 冷启动 console error、page error、失败请求和 HTTP 4xx 均为零。

自动截图保存在本地忽略目录 `output/playwright/m0-visual/`；Chrome/Edge 两种分辨率的画布边界和运行指纹均已人工复核。

`npm run perf` 已建立，但 M0 会以退出码 `2` 明确报告 `PERF_SCENARIO_NOT_AVAILABLE`。真实性能场景属于 M1 门禁，不在本轮生成虚假结果。

## 5. 已知非阻塞项

- production build 会提示 Phaser 主 chunk 超过 500 kB；M0 空场景运行与构建均正常，是否拆包应在出现真实加载目标后评估，当前不为消除提示提前引入分包复杂度。
- §9.6 的覆盖率数字是建议目标而非 M0 退出硬门禁；当前总行覆盖率 89.24%，但 domain/config/simulation 的分支覆盖仍低于建议值。关键契约已由具名向量和浏览器证据锁定，后续里程碑在加入真实规则分支时继续提高，不用无业务意义的测试凑数。

## 6. 独立审查闭环

- application/domain/simulation 经三轮只读审查和三个相互独立的 repair agent，所有修复均先复现、转 RED 测试，再做最小修复。
- 修复过的边界包括非法 tick/载荷、畸形 replay、reset cutover、自然流失 eligibility、newborn、体积守恒和确定性向量元数据。
- config/fingerprint 经独立复审后修复重复 JSON 键与 PNG `gAMA` 跨端差异；第二轮复审通过。
- Phaser/DOM 冷启动复审修复 favicon 404；真实 Chrome/Edge 控制台与网络门禁通过。
